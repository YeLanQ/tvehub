# 单元：TvE 助手面板

## 操作面

| 动作 | 入口 | 行为 |
|---|---|---|
| 开/关面板 | **仅首页**标题栏「✦ 助手」按钮 | 全局单例浮动窗口（无边框，可拖拽，位置记忆）；隐藏 ≠ 关闭，状态保留 |
| 项目工作区 | 左栏项目列表 | **项目目录即工作区**：点击仅切换对话/资产上下文，不需要在编辑器打开；清单只读自项目管理页（最近项目）；当前编辑器打开的项目带绿点 |
| 会话管理 | 聊天头部会话切换器（会话名 ▾）+ 右侧 ＋ | 下拉列出当前工作区全部会话（点击切换、× 删除），底部「＋ 新建会话」；首条用户消息自动命名会话 |
| 添加项目 | 左栏「＋ 添加项目」 | （已移除）项目增删只在首页项目管理页维护，助手清单只读 |
| 新建项目 | 左栏「＋ 新建项目」 | （已移除）同上；AI 工具 project.create 仍可用（经权限门控） |
| 新会话 | 聊天头部「＋新会话」 | 当前工作区下新建空白会话 |
| @插入文件 | 输入框左侧 @ | 资产列表搜索 → `asset.read` 读文本（≤512KB，二进制拒绝）→ fenced 块入输入框 |
| 卡片/供应商 | 左栏底部「⚙ 设置」 | 右栏就地切换：智能体卡片（人设/自定义提示词/开场白/标签/模型与温度覆盖/导入导出 JSON）+ 供应商（OpenAI 兼容地址/Key/模型，可拉取模型列表） |
| 对话 | 输入框 Enter 发送 / Shift+Enter 换行 | 流式输出；工具调用显示 ⚙ 芯片 |

## 规则/要点

- **未打开编辑器也能编辑**：`scene.list / asset.list / asset.read / asset.write`
  支持显式 `root` 参数（助手自动注入当前工作区项目根），直读直写项目目录文件
  （含 .scene 文本）；`asset.write` 自动建父目录、≤512KB、拒路径穿越。
- **节点级与预览工具依赖编辑器会话**（`node.* / preview.* / scene.open/save`）：
  项目未在编辑器打开时报"没有活跃的编辑器窗口"，助手会改用文件级工具。
- 助手工具与外部控制端**共用同一权限清单**：首页「开发者服务 → 工具权限」关闭的
  工具（assetWrite/projectCreate/assetRead 等同样在清单中），助手调用同样被拒。
- 命令执行统一走内部 devtools 桥（编辑器窗口执行器常开，与控制服务器开关无关）。
- 会话按项目根隔离（`tve:ai:conv-index`）；卡片/供应商/窗口位置持久化在应用配置
  目录（ui-state KV `tve:ai:*`）；API Key 仅存本机。
- 模型选择用 ui-kit ComboBox（拉取的模型列表为候选，可手填）；无供应商配置时
  聊天区显示引导卡片；卡片可覆盖全局模型与温度。
