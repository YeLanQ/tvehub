# 编辑器总览

tve 编辑器是面向 3D 场景创作的可视化编辑器，采用停靠（dock）布局，内置场景编辑、动画编辑、脚本工作台、网页预览与构建导出。

## 双窗口架构

桌面端（Tauri）采用双窗口架构：

- **首页窗口**：项目管理、模板、偏好设置、创意工坊、开发者服务；
- **编辑器窗口**：打开项目后显示，包含工具栏、停靠面板与中央工作区。

工具栏「关闭」返回首页；首页「打开项目」回到编辑器。浏览器环境回退单窗口内的视图切换。

## 编辑器布局

编辑器窗口自上而下：

```
┌──────────────────────────────────────────────┐
│ 工具栏：项目信息 · 构建 · [场景|预览|脚本] · 撤销 · 保存 · 关闭 │
├─────────┬──────────────────────────┬─────────┤
│ 左侧停靠区 │         中央工作区           │ 右侧停靠区 │
│ 层级      │   场景视口 / 网页预览 / 脚本工作台  │ 属性      │
├─────────┴──────────────────────────┴─────────┤
│ 底部停靠区：控制台 · 动画 · 资产                       │
└──────────────────────────────────────────────┘
```

- **停靠面板**共 5 种：层级、属性（检查器）、控制台、资产、动画；
- 面板可拖拽在左/右/底部三个停靠区间移动、合并为标签页，拖拽标题栏调整位置；
- 分隔条可拖拽调整各区宽度/高度；
- 布局自动持久化，下次打开恢复。

## 工具栏

| 元素 | 说明 |
| --- | --- |
| 项目信息 | 项目名 + 当前场景名，点击打开/关闭**项目设置** |
| 构建 | 打开构建导出面板 |
| 视图模式切换 | **场景**（编辑视口）/ **预览**（网页预览）/ **脚本**（脚本工作台） |
| 撤销 | 撤销上一次场景修改（Ctrl+Z） |
| 保存 | 保存当前场景（Ctrl+S）；有未保存修改时显示圆点标记 |
| 关闭 | 关闭项目返回首页（Ctrl+W）；有未保存修改时提示 |

## 视图模式

- **场景**：3D 编辑视口（默认）；
- **预览**：把当前场景导出为独立网页并在内嵌 iframe 中运行（见[预览与构建](preview-build.md)）；
- **脚本**：Monaco 脚本工作台（见[脚本工作台](scripting.md)）。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| W / E / R | 视口切换 移动 / 旋转 / 缩放 工具 |
| F2 | 重命名：层级/视口/检查器上下文重命名选中节点；资产面板内重命名选中资产 |
| Ctrl+Z | 撤销 |
| Ctrl+S | 保存场景；脚本工作台内保存当前脚本 |
| Ctrl+W | 关闭项目 |
| Shift+点击 | 层级/视口多选（范围或切换） |
| Ctrl/Cmd+点击 | 多选切换 |
| Ctrl+S（脚本工作台） | 保存并编译当前脚本 |

> 节点删除经层级/检查器右键菜单执行；脚本工作台内 Ctrl+S 由 Monaco 处理为「保存并编译」。

## 控制台

底部停靠区「控制台」面板：接收编辑器日志、脚本 `engine.log/warn/error` 输出、预览页转发的 console 与错误，右上角「清除」清空。
