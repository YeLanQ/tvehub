# 编辑器总览

tve 编辑器是面向 3D 场景创作的可视化编辑器，采用停靠（dock）布局，内置场景编辑、动画编辑、脚本工作台、网页预览与构建导出。

## 双窗口架构

桌面端（Tauri）采用多窗口架构：

- **首页窗口**：项目管理、模板、偏好设置、创意工坊、开发者服务；
- **编辑器窗口**：打开项目后显示，包含工具栏、停靠面板与中央工作区；
- **场景图窗口**：从首页项目卡片右键「打开场景图」打开，可视化节点编辑运行时行为（见 [场景图](graph.md)）。

工具栏「关闭」返回首页；首页「打开项目」回到编辑器。浏览器环境回退单窗口内的视图切换。

## 编辑器布局

编辑器窗口自上而下：

```
┌──────────────────────────────────────────────┐
│ 工具栏：项目信息 · 构建 · [场景|布局|预览|脚本] · 撤销 · 保存 · 关闭 │
├─────────┬──────────────────────────┬─────────┤
│ 左侧停靠区 │         中央工作区           │ 右侧停靠区 │
│ 层级      │   场景视口 / 网页预览 / 脚本工作台  │ 属性      │
├─────────┴──────────────────────────┴─────────┤
│ 底部停靠区：控制台 · 动画 · 资产                       │
└──────────────────────────────────────────────┘
```

### 停靠面板系统

- **停靠面板**共 5 种：层级（hierarchy）、属性（检查器）、控制台、资产、动画；
- 默认布局：左区 = 层级，右区 = 属性，底部 = 控制台 / 动画 / 资产三个标签页；
- **拖拽移动**：按住面板标签拖动（移动约 4px 才算拖拽，否则视为点击激活）；
  - 落到左/右/底部任一停靠区 = 停靠到该区（按落点横向位置插入标签排列）；
  - 拖到空白处 = 变**浮动窗口**（可拖拽标题栏移动、调整大小；标题栏 ✕ 关闭后回到来源停靠区）；
  - 浮窗拖回任一停靠区即重新停靠；拖拽中按 Esc 取消；
- **合并标签页** = 同一停靠区里放多个面板，点击标签切换；
- 同一面板全编辑器只有一个实例（拖走 = 移动，不是复制）；
- **空停靠区**折叠为细条，仍是合法的拖放落点；
- **分隔条**可拖拽调整各区宽度/高度（左区约 180~560px、右区约 200~560px、底部约 96~480px）；
- 布局（面板位置 + 各区尺寸 + 浮窗状态）自动持久化到浏览器本地存储，下次打开恢复；
- **动画聚焦模式**：动画编辑器进入聚焦编辑时锁定面板布局，避免编辑中误动其他面板。

## 工具栏

| 元素 | 说明 |
| --- | --- |
| 项目信息 | 项目名 + 当前场景相对路径，点击打开/关闭**项目设置**（悬停显示项目完整路径） |
| 构建 | 打开构建导出面板（见[预览与构建](preview-build.md)） |
| 视图模式切换 | **场景**（编辑视口）/ **布局**（UI 画布编辑）/ **预览**（网页预览）/ **脚本**（脚本工作台） |
| 撤销 | 撤销上一次场景修改（Ctrl+Z）；无历史时禁用 |
| 保存 | 保存当前场景（Ctrl+S）；有未保存修改时显示圆点标记；脚本页签下同时保存全部脏脚本 |
| 关闭 | 关闭项目返回首页（Ctrl+W）；有未保存修改时先弹确认（保存并关闭 / 放弃修改 / 返回） |

预览与脚本模式会暂停编辑器视口的渲染循环以节省资源。

## 视图模式

| 模式 | 内容 | 典型操作 |
| --- | --- | --- |
| **场景** | 3D 编辑视口（默认） | 摆节点、调材质、K 动画 |
| **布局** | UI 画布独占渲染的 2D 布局视口 | 排 UI（选中 UI 节点自动切换过来） |
| **预览** | 把当前场景导出为独立网页并在内嵌 iframe 中运行 | 试玩、设备仿真、看真实运行语义 |
| **脚本** | Monaco 脚本工作台 | 写 TS 脚本、着色器源码 |

四种模式共用同一套停靠面板（层级/检查器在预览/脚本模式同样可用）。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| W / E / R | 视口切换 移动 / 旋转 / 缩放 工具 |
| F2 | 重命名（按上下文）：层级/视口/检查器中重命名选中节点；资产面板内重命名选中资产 |
| Ctrl+Z | 撤销 |
| Ctrl+S | 保存场景；脚本工作台内为「保存并编译」当前脚本 |
| Ctrl+W | 关闭项目 |
| Ctrl+D | 复制当前多选集（层级节点） |
| Shift+点击 | 层级/视口多选（范围选择） |
| Ctrl/Cmd+点击 | 多选切换（加入/移除） |

> 节点删除经层级/检查器右键菜单执行；脚本工作台内 Ctrl+S 由 Monaco 处理为「保存并编译」。

## 控制台

底部停靠区「控制台」面板集中显示编辑器全部输出：

- **消息级别**：信息(ⓘ) / 警告(⚠) / 错误(✖) / 引擎(⚙) / 成功(✓)；顶部按钮组可按级别过滤（点击某级别只看该级，再点恢复全部），右侧显示「过滤后 / 总数」计数；
- **来源**：编辑器动作（创建/删除/重命名节点、保存等）、脚本 `engine.log/warn/error`、预览页转发的 console 与错误（`[预览]` 前缀）、脚本编译失败、着色器编译失败、构建日志；
- 上限 **500 行**，超出丢弃最旧；右上角「清除」清空。

## 撤销与保存

- 场景修改（添加/删除/移动/属性编辑/变换/组件增删）均进入撤销历史，Ctrl+Z 或工具栏「撤销」回退；
- 撤销粒度为**整节点快照**：一次拖拽、一次批量多选操作、一次组件添加都算一步，回退即整步还原；
- 保存 = 把当前场景写入场景文件；有未保存修改时保存按钮带圆点标记，关闭项目时提示保存；
- 「保存」在脚本页签下会同时保存工作台里全部脏脚本。
