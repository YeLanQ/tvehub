# 预览与构建

## 网页预览

工具栏切到「预览」：把当前场景导出为独立网页，经本地静态服务在内嵌 iframe 中运行（与编辑器画布无关，真实运行时语义）。

- **进入预览**：自动导出（保存当前编辑场景 + 编译全部脚本 + 打包运行时）并启动服务；
- **刷新**：重新导出当前编辑内容并重载（服务保持运行，按需读盘）；
- **在浏览器打开**：用默认浏览器打开当前预览地址；
- **停止预览**：停止服务释放端口；离开预览页签自动停止；
- 预览页的 console 与错误经 postMessage 转发到编辑器控制台（前缀 `[预览]`）；
- 物理按项目配置（启用开关 + 所选引擎）包含对应运行时。

## 构建导出

工具栏「构建」打开构建面板，把场景打包为可部署产物。

### 渠道

| 渠道 | 状态 |
| --- | --- |
| Web | 打包为可部署的静态网页（player 运行时 + 场景 + 资产） |
| 微信小游戏 | 即将支持（按钮禁用） |

### 配置

| 项 | 说明 |
| --- | --- |
| 构建场景 | 多选项目内 `.scene`；须指定**主场景**（产物入口加载的场景） |
| 页面标题 | Web 页面 `<title>` |
| 调试模式 | 保留运行日志转发（默认开） |
| 导出模板 | 可多选；首个生成 `index.html`，其余生成 `index-<模板>.html`；多文件与单页模板不能混选；支持 exe 旁 `public/exports/web` 的用户自定义模板 |
| 资产 gzip | 归档资产（多文件写 `assets.gzip`；单页 base64 内联）；可配 gzip 资源远程基址 |
| 发布模式 | 资源 uid 重命名 + 引用重写 + JSON 压缩 |
| CDN 模式 | 渲染运行时不内嵌，从配置的 CDN 地址在线加载 |

配置随项目保存在项目根 `build.config.json`。

### 流程与产物

1. 构建前自动保存当前编辑场景与全部脏脚本（按磁盘内容构建）；
2. 按项目配置打包物理引擎运行时（未启用物理的产物不打包引擎，减小体积）；
3. 编译 `src/**.ts` 脚本并入产物（编译失败的脚本不参与构建，控制台报错）；
4. Rust 端打包落盘；完成后可一键打开输出目录；缺失资产会被跳过并在控制台警告。

产物为纯静态文件，可直接部署到任意静态服务器。

## 开发者服务（桌面端）

首页「开发者服务」分区提供**本地控制服务器**（TCP 换行分隔 JSON + MCP 端点）：编辑器窗口执行命令（场景读写、节点增删改、资产、预览截图等），可配置端口与工具权限、复制 MCP 配置接入外部 AI/工具链。
