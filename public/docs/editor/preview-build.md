# 预览与构建

## 网页预览

工具栏切到「预览」：把当前场景导出为独立网页，经本地静态服务在内嵌 iframe 中运行（与编辑器画布无关，**真实运行时语义**——所见即发布效果）。

### 预览工具条

| 按钮 | 行为 |
| --- | --- |
| 刷新 | 重新导出当前编辑内容并重载（保存当前场景 + 脏脚本 → 重编译 → 重载 iframe；服务保持运行，按需读盘） |
| 在浏览器打开 | 用默认浏览器打开当前预览地址（同一本地服务，可用于 DevTools 调试） |
| 停止预览 | 停止服务释放端口；离开预览页签自动停止 |
| ✕ | 关闭预览页签返回场景 |

### 导出与运行

- **进入预览**：自动导出（保存当前编辑场景 + 编译全部脚本 + 打包运行时）并启动服务；
- 导出内容写入项目下临时目录（`<项目>/.tmp/web-preview`），本地静态服务监听固定端口 **39110**（外部浏览器可访问）；
- 导出文件 = three 运行时 + 播放器（player）+ `config.json`（项目配置）+ 全量编译的 `src/**.js`（单脚本编译失败跳过并在控制台告警）；
- 可选运行时按项目配置按需打包：物理引擎（启用开关 + 所选引擎）、WebGPU 构建（渲染后端为 WebGPU/自动时，约 670KB，不可用时播放器自动回退 WebGL2）；
- 预览页的 console 与错误经 postMessage 转发到编辑器控制台（前缀 `[预览]`；构建勾选「调试模式」时产物同样转发）。

### 设备仿真

预览工具条提供设备仿真：内置 iPhone SE / iPhone 14 / iPhone 15 Pro / 安卓 360×800 / Pixel 7 / iPad 等机型（可切横竖屏）、自定义宽高与 DPR（1~4）；缩放滑条 25%~200% + 「适应」一键适配。设备设置按项目记忆。配合「屏幕方向」「缩放模式」项目设置可完整验证移动端适配效果。

## 构建导出

工具栏「构建」打开构建面板，把场景打包为可部署产物。

### 渠道

| 渠道 | 状态 |
| --- | --- |
| Web | 打包为可部署的静态网页（player 运行时 + 场景 + 资产） |
| 微信小游戏 | 即将支持（按钮禁用） |

### 配置

| 项 | 说明 |
| --- | --- |
| 构建场景 | 多选项目内 `.scene`；须指定**主场景**（产物入口加载的场景，必须在所选场景内）；运行时可用 `?scene=场景名` 切换入口场景 |
| 页面标题 | Web 页面 `<title>`（默认项目名） |
| 调试模式 | 保留运行日志转发（默认开）；与发布模式互斥 |
| 发布模式 | 资源 uid 重命名 + 引用重写 + JSON 压缩（产物更小、路径不可读）；与调试模式互斥 |
| 导出模板 | 可多选；首个生成 `index.html`，其余生成 `index-<模板>.html`；多文件与单页模板不能混选（混选自动切换并提示）；支持 exe 旁 `public/exports/web` 的用户自定义模板 |
| 资产 gzip | 归档资产（多文件写 `assets.gzip`；单页 base64 内联）；可配 gzip 资源远程基址（空 = 本地读取） |
| CDN 模式 | 渲染运行时（three.js）不内嵌，从配置的 CDN 地址在线加载；未填地址时仍内嵌并黄字警告 |

配置随项目保存在项目根 `build.config.json`（channel / scenes / mainScene / title / debug / templates / gzip / release / cdn / gzipBase / cdnBase），重开面板读回，旧配置兼容。

### 流程与产物

1. 构建前自动保存当前编辑场景与全部脏脚本（按磁盘内容构建）；
2. 按项目配置打包可选运行时（未启用的不打包，减小体积）：物理引擎（启用开关 + 所选引擎）+ WebGPU 构建（渲染后端为 webgpu/auto 时）；
3. 编译 `src/**.ts` 脚本并入产物（编译失败的脚本不参与构建，控制台报错）；
4. 组装导出模板（`index.html` / 单页内联），Rust 端打包落盘到 **`<项目>/build/web/`**；完成后可一键打开输出目录；缺失资产会被跳过并在控制台列出。

产物为纯静态文件，可直接部署到任意静态服务器（或对象存储 + CDN）。产物内资产读取顺序：内联 gzip 包 → 内联资产表 → `assets.gzip` 归档 → 磁盘文件。

### 构建结果区

面板底部显示结果摘要：单页/多文件 · gzip · 发布 · CDN · 模型转 bin 数量 · 场景数 · 资产数 · 主场景，以及缺失资产列表；按钮：打开构建目录 / 预览（起本地静态服务服务构建产物，iframe + 在浏览器打开 + 停止）/ 开始构建。

### 发布模式细节

勾选后构建做三件事：资源文件名改为内容 uid（防止路径探测、利于长缓存）；场景/材质/预制体内的全部资产引用同步重写；JSON 压缩去空白。调试模式则保留可读路径与日志转发，便于排查线上问题。

## 开发者服务（桌面端）

首页「开发者服务」分区提供**本地控制服务器**（TCP 换行分隔 JSON + MCP 端点，默认端口 39100）：编辑器窗口执行命令（场景读写、节点增删改、资产、预览截图等），可配置端口与工具权限（约 19 个工具开关、逐个启停）、复制 MCP 配置接入外部 AI/工具链。详见[项目管理 › 开发者服务](projects.md)。
