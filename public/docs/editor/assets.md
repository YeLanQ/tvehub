# 资产系统

底部停靠区的「资产」面板管理项目内全部资产：左栏文件夹树 + 右栏资产内容，底部状态栏显示选中数与条目数。

## 面板布局与工具栏

- **双栏**：左 = 文件夹树（缺省展开；折叠状态按项目持久化，重开编辑器/工程后还原）；右 = 网格/列表视图（目录在前、文件在后，按所选排序规则排列）；
- **工具栏**：后退 / 前进 / 上级 + 面包屑（可点击跳转，根显示「根」）+ 搜索框（递归当前目录）+ 类型筛选 + 排序（按名称/按类型/按大小）+ 视图切换（网格/列表）+ 导入 / 导入目录 + 刷新；
- 初始目录固定 `assets`；类型筛选支持：场景 / 材质 / 着色器 / 脚本 / JSON / 纹理 / TextureCube / 模型 / 预制体 / 动画；
- **拖拽**：面板内拖到目录节点 = 移动；从系统拖入文件 = 导入到当前目录（显示「松开鼠标 · 导入资产到 X」覆盖层）；模型等资产还可拖入 3D 视口直接创建节点。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `assets/` | 场景、模型、纹理、音频、材质、着色器、动画、预制体等资产 |
| `assets/prefabs/` | 预制体 |
| `src/` | TS 脚本（右键可新建脚本；不可导入二进制资产/新建场景） |
| `internal/` | 内置只读资产（内置材质、着色器、模板纹理等），只可引用、可「复制到项目」后修改 |

`assets` 与 `src` 为项目固定根目录（不可重命名/删除/移动）；新建资产名校验禁止 `/ \ : ..` 等非法字符。

## 资产类型

| 类型 | 扩展名 | 说明 |
| --- | --- | --- |
| 场景 | `.scene` | 3D 场景；项目设置中可设主场景 |
| 模型 | glb / gltf / fbx / obj | 导入后可添加到场景（拖入视口亦可） |
| 纹理 | png / jpg / jpeg / webp / bmp / hdr | 图片资产 |
| 音频 | mp3 / wav / ogg / m4a / aac / flac | 音频文件，绑定音源节点/组件 |
| 脚本 | `.ts` | TS 脚本，双击进入脚本工作台 |
| 动画剪辑 | `.anim` | 关键帧动画剪辑，经动画剪辑组件绑定 |
| 状态机 | `.fsm` | 逻辑资产：状态图（状态/事件/定时/参数条件过渡），绑定 FSM Runner 节点运行 |
| 行为树 | `.bt` | 逻辑资产：组合/装饰/叶子节点树，绑定 BT Runner 节点运行 |
| 材质 | `.mat` | 材质资产（含天空盒材质）；与着色器分离 |
| 着色器 | `.shader` | PBR / Unlit / 卡通 / 自定义（custom）等渲染程序 |
| 预制体 | `.prefab` | 节点子树模板，可实例化与回写更新 |
| TextureCube | `.texcube` | 立方体纹理（天空盒用；六面图或全景图来源） |

## 新建与导入

- 右栏空白处/目录右键菜单：**新建目录**、新建场景、新建脚本（基础模板或创意工坊原型）、新建预制体、新建动画（`.anim`）、新建材质、新建着色器（PBR/Unlit/卡通/自定义）、新建天空盒（程序化天空/立方体天空盒）、新建 TextureCube、**新建逻辑 ▸ 状态机 / 行为树**（`.fsm`/`.bt`）；
- **创意工坊**（右键菜单「创意工坊 ▸ 标签 ▸ 内容」，任意可编辑目录可调起）：按仓库内容新建项目资产——
  `Code` 标签 → 脚本（固定创建在 `src/`），`Effect` 标签 → 当前目录的 `.shader` 资产；
- **导入**：工具栏「导入」多选文件 /「导入目录」整个文件夹；也可从系统直接**拖入文件**到面板（松开即导入到当前目录）；文本文件按文本、二进制（图片/模型/音频等）按 base64 写入；
- 内置资产右键「**复制到项目**」：按类型落到约定目录（材质 → `assets/materials`、着色器 → `assets/shaders`、预制体 → `assets/prefabs`、动画 → `assets/animations`、脚本 → `src`、图片 → `assets/textures`、模型 → `assets/models`、音频 → `assets/audio`），重名自动加后缀。

## 资产操作

| 操作 | 行为 |
| --- | --- |
| 双击 | 目录 = 进入；`.scene` = 打开场景；模型/音频 = 添加到场景；`.ts`/`.shader` = 打开工作台；`.fsm`/`.bt` = 打开可视化逻辑编辑器（状态图 / 行为树画布） |
| 右键菜单 | 打开、添加到场景（模型/音频等）、实例化到场景（预制体）、复制、重命名（F2）、删除、复制路径、刷新等 |
| 重命名 | 文件名未带后缀自动补原扩展名（目录不补）；**脚本重命名会同步改写场景内全部脚本组件引用与工作台标签页**；普通资产重命名/移动会跟随改写当前场景路径与主场景配置 |
| 删除 | 确认弹窗（含目录时提示不可恢复）；**脚本删除会同步移除场景内引用它的组件**；多选删除后如当前目录被删则回退 `assets` |
| 刷新 | 重新扫描磁盘内容（外部改动了项目文件后使用） |

## 材质与着色器

- 材质与着色器分离：材质挂载一个着色器，参数按着色器声明的渲染分支呈现；
- 内置材质（`internal/`）只读，检查器中可「复制为项目材质」后编辑参数/切换着色器；
- 新建材质默认挂内置 PBR 着色器；新建着色器按渲染分支基名（PBR/Unlit/Toon）去重；
- 渲染分支只有三个出口（PBR / Unlit / 卡通）+ 两个天空程序（内置资产）：`.shader` 用 `Base`
  声明走哪个分支（天空程序按 `PreviewType=Skybox` 标签识别），引擎据此映射到现成材质、不编译源码；
- 自定义着色效果写在着色器资产里（`Base` + `Hook` 块）：Base 选渲染分支、Hook 是叠加其上的效果片段，
  可在检查器「编辑源码」（Monaco GLSL）中改写，用 `Properties` 暴露材质参数——详见[着色器与自定义效果](shaders.md)；
- 效果在两种渲染后端都生效：WebGL 注入 GLSL，WebGPU 由引擎把**同一份 Hook 翻译为 TSL** 接节点材质端口
  （契约一致；Fragment 端口与受控子集外的写法在 WebGPU 下不生效，控制台给出原因）。

### 材质参数全集

材质参数按渲染分支分组呈现（`.mat` 内为平铺字段，脚本/外部工具可直接读写）：

| 分组 | 字段 |
| --- | --- |
| 贴图 | 基础色贴图 map、法线贴图 normalMap、金属度贴图 metalnessMap、粗糙度贴图 roughnessMap、自发光贴图 emissiveMap |
| 基础 | 基础色 color、金属度 metalness 0..1、粗糙度 roughness 0..1 |
| 高光 | 高光强度 specularIntensity、高光着色 specularColor、折射率 ior 1.0~2.333 |
| 自发光 | 自发光色 emissive、强度 emissiveIntensity 0..10、启用开关 emissionEnabled |
| 清漆 | clearcoat 0..1、clearcoatRoughness、启用开关 clearcoatEnabled |
| 光泽（Sheen） | sheen 0..1、sheenColor、sheenRoughness、启用开关 sheenEnabled |
| 透射 | transmission 0..1、thickness 0..100、attenuationColor、attenuationDistance、启用开关 transmissionEnabled |
| 各向异性/虹彩 | anisotropy、anisotropyRotation、iridescence、iridescenceIOR |
| 透明 | 不透明度 opacity 0..1、Alpha 裁剪阈值 alphaClipThreshold（>0 时贴图 alpha 低于阈值的部分直接裁掉）、wireframe 线框 |
| 卡通（Toon 分支） | 明暗档数 toonSteps 2..6、明暗强度 toonShadowStrength、轮廓开关 outlineEnabled、轮廓色 outlineColor、轮廓宽度 outlineWidth（法线外扩量 = 值 × 包围半径） |

- Unlit 分支只消费 基础色/不透明度/Alpha 裁剪/线框（其余参数忽略）；
- 透明规则：opacity < 0.999 或（有基础色贴图且未开 Alpha 裁剪）自动走透明混合。

## 预制体

- 层级面板右键「存储为预制体…」把选中节点子树存为 `assets/prefabs/` 下的 `.prefab` 资产（重名自动去重）；
- 预制体资产可拖入/添加到场景生成实例（层级中图标为**绿色**）；
- 实例修改后右键「更新预制体（资产名）」把改动回写资产；
- 预制体实例在场景文件中以 `prefab` 字段记录来源资产路径，正常参与变换/组件编辑与脚本运行。
