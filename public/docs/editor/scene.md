# 场景编辑

## 层级面板

左/右停靠区的「层级」面板以树状展示**当前视图域**的节点，场景层级与 UI 层级按视图分离。行数据由 **Rust 后端在权威场景图上单次 DFS 计算**（`scene_hierarchy_rows`：域过滤 + 名称搜索一次完成），前端只做折叠裁剪与渲染——大量节点下编辑/拖动不会卡层级面板（图变更防抖拉取，不逐帧全树重算）。

- **场景视图**：场景树——全部非 UI 域节点（UI 画布子树不出现，UI 相关编辑在布局视口进行）；
- **布局视口**：UI 树——UI 画布子树与 UI 节点（画布挂在组下的，画布作为树的根直接列出；画布子树内的普通组/网格随画布同域显示）；
- 两棵树与视口点选同口径：布局视口内只有 UI 域节点可被选中（其余选择路径——创建/重父级/脚本等同样被引擎选中范围拦截），跨域拖拽不可达。

### 基础操作

- **选中**：单击选中；Ctrl/Cmd+点击 多选切换；Shift+点击 范围多选；
- **搜索**：顶部搜索框按名称子串过滤（保留祖先路径；搜索时忽略折叠状态）；无匹配显示「无匹配节点」；
- **折叠/展开**：点击箭头折叠子树；拖拽悬停折叠节点时自动展开；折叠状态按 项目+场景 持久化（localStorage），重开编辑器/工程后还原，缺省全部展开；
- **可见性**：行尾小眼睛切换显示/隐藏（隐藏 = 渲染关闭 + 取消激活；再点一步恢复；走一次撤销）；
- **重命名**：右键「重命名」或 F2（弹出统一输入框）；
- **删除**：右键「删除」（红色项；根节点不可删除/重命名）；多选时删除整个多选集；
- **复制**：右键「复制」或 **Ctrl+D**，复制当前多选集（自动剔除互为子孙的冗余项；根不可复制；完成后选中新副本，一步撤销）。

### 右键菜单

节点行右键：

| 菜单项 | 说明 |
| --- | --- |
| 添加节点 | 子菜单见下节 |
| 重命名 | 同 F2 |
| 复制 | 同 Ctrl+D（根禁用；多选时复制整个多选集） |
| 对齐到当前视口 | 仅相机节点：把该相机节点的位姿与取景参数写为当前视口相机的观察角度（透视同步 fov，正交按当前取景折算正交半高）；一次撤销可还原 |
| 存储为预制体… | 把子树存为 `assets/prefabs/` 下的 `.prefab` 资产（重名自动去重；节点记录来源引用，可撤销） |
| 更新预制体（资产名） | 仅预制体实例：把当前子树覆盖写回来源 `.prefab` 资产 |
| 删除 | 根禁用；多选删全部 |

空白处右键：仅「添加到根节点」（同款添加子菜单）并取消选中。

### 拖拽移动

按住行拖拽（约 5px 阈值），松开时按**落点在目标行内的纵向位置**判定：

| 落点位置 | 行为 |
| --- | --- |
| 上部 0~25% | 放到目标**上方**（同级） |
| 中部 25~75% | 放**内部**（成为子级；折叠目标自动展开） |
| 下部 75~100% | 放到目标**下方**（同级） |

- 拖到根行/空白 = 收进根节点；拖出面板外无效；
- 拖入自身或自身子树被拒绝（防成环，控制台警告）；
- 多选整体拖动（保持相对顺序追加到目标处）；
- 拖拽时有「虚线框 + 名称」幽灵跟随。

## 可创建的节点类型

右键「添加节点」菜单（分组固定）：

| 分组 | 类型 |
| --- | --- |
| 网格 | Box / Sphere / Plane / Quad / Cylinder / Cone / Torus / Capsule（基元由几何注册表驱动） |
| 灯光 | Point Light / Directional Light / Spot Light / Ambient |
| 相机 | Camera |
| 空组 | Group |
| 音频 | Audio Source |
| 粒子 | Particle System（粒子发射器，见下文） |
| 地形 | Terrain（程序化地形，参数经检查器调整） |
| 雾 | Linear Fog / Exponential Fog / Height Fog |
| 导航 | Nav Area（可行走区域烘焙）/ Nav Agent（寻路移动体） |
| 逻辑 | FSM Runner（状态机运行器）/ BT Runner（行为树运行器），见下文 |
| UI | UI Canvas / Text / Image / Button / Layout（见 [UI 系统](ui.md)） |
| 天空盒 | Procedural Skybox（程序化天空）/ Cube Skybox（立方体贴图） |
| 脚本节点 | 由脚本 `@nodeType` 声明的类型（有声明时出现；创建即自动挂载对应脚本） |

常用类型的关键默认值：

| 节点 | 默认参数 |
| --- | --- |
| Camera | 透视 fov 50、near 0.1、far 20、清除标志天空盒、Culling Mask 全部 |
| 点光/聚光 | 强度 1、照射距离 10、衰减指数 2、阴影关闭（聚光另有半角 45°、边缘柔和 0.2） |
| 粒子 | 循环、Additive 混合、软圆点精灵（详见检查器文档） |

模型资产经资产面板「添加到场景」或拖入创建为模型网格节点。

### 逻辑运行器（状态机 / 行为树）

把 `.fsm` / `.bt` 逻辑资产绑到场景里跑的载体节点（FSM Runner / BT Runner）。典型闭环：

1. 资产面板「新建 ▸ 状态机 / 行为树」创建逻辑资产并编辑（状态图 / 行为树画布）；
2. 层级「添加节点 ▸ 逻辑」创建运行器，检查器 Asset 下拉绑定资产；
3. 运行器随编辑器渲染循环推进（编辑态即可看到状态切换，检查器 Live 区实时显示）；
4. 预览 / 构建产物中同样运行；脚本经 `engine.logic` 喂事件、写黑板、订阅状态切换、注册行为树动作（见 [engine.logic](../sdk/engine.md)）。

要点：

- 运行器只持设置（绑定资产 / Auto Start / Speed 时间倍率）；当前状态、黑板、运行记忆是**运行态**，不进场景文件；
- 状态机过渡 = 事件（脚本 `engine.logic.fire`）/ 定时 / 参数条件三类，出边按定义顺序首个满足者触发；进入新状态即清空已收事件；
- 行为树动作叶子在编辑器预览中按成功处理；运行时经 `engine.logic.onAction` 注册行为（未注册同样按成功）；
- 编辑器里重新保存逻辑资产后，绑定的运行器**热重建**（不必重开场景），运行开关保持；
- 检查器可发射事件、强制切换状态、编辑参数黑板、暂停/重启（运行态操作，不进撤销历史）。

## 变换语义

- 位置/缩放：米制；旋转：度制欧拉角 XYZ；
- 坐标系右手系、Y 向上，前向 = **-Z**（灯光照射方向、相机取景方向、粒子锥形发射方向均为本地 -Z；给「角色」建模/导入时让脸朝 -Z 可与 `lookAt` 等脚本语义对齐）；
- 检查器与脚本共享同一套变换语义（脚本侧 `entity.rotate` 等均为度）。

## 视口

中央 3D 视口：

- **选择**：左键点击节点（点击空白取消选中；根节点不可从视口选中）；
- **变换工具**：顶部工具条 移动 (W) / 旋转 (E) / 缩放 (R)，拖拽 Gizmo 变换；数值输入框支持**拖动调节**（按住 Shift = 1/10 精细步进），点击进入键盘编辑；
- **坐标系**：本地（对象自身轴）/ 世界（场景固定轴）切换；
- **轨道漫游**：右键/中键拖拽旋转视角，滚轮缩放；
- **预览渲染**：视口可切换用场景相机节点取景渲染（相机辅助线、网格等编辑辅助物同步隐藏）；
- **拖放创建**：资产面板的模型/材质等资产可直接拖入视口创建节点；
- 辅助物：地面网格、相机盒体与视锥线框（按项目设计分辨率）、灯球、gizmo、选择框；**灯光辅助线仅选中该灯时显示**——点光 = 范围环（半径随 Range，Range=0 无限远时收拢隐藏）、聚光 = 光锥（底圆 + 四条斜线，长度随 Range、半径随 Spot Angle，Range=0 时收拢隐藏）、平行光 = 方向箭头。

### 运行时相机选择

预览/构建产物按以下优先级取渲染相机（编辑器视口的「预览渲染」同规则）：

1. 第一个**非编辑器相机**的相机节点；
2. 没有则第一个相机节点；
3. 都没有则使用内置缺省取景（透视 fov 50，恒全层可见）。

相机节点只是记录位姿的容器，每帧把位姿回填给渲染相机——因此脚本/动画/物理驱动的相机运动会正常生效。编辑器自由视角不受相机节点影响（恒全层可见，避免编辑时对象凭空消失）。

## 粒子系统

Particle System 节点是场景中的粒子发射器（常规粒子系统语义子集），入图即在视口中实时模拟，参数改动实时生效：

- **发射方向**：Cone / Box 沿节点**本地 -Z** 发射（与灯光、相机的前向一致），旋转节点即改变喷射方向；Sphere / Hemisphere 由球心向外；
- **模拟空间**：`Local` 粒子跟随节点移动（火把/引擎尾焰），`World` 粒子留在世界空间（烟迹/拖尾）；切换会清空当前粒子；
- **循环与预热**：循环系统持续发射；非循环系统发射 `Duration` 秒后停止，粒子全部消亡即播完（检查器 ▶ 可重播）；`Prewarm` 让循环系统入图/重启时直接以稳态密度出现（一步铺满，不逐步积累）；
- **随寿命变化**：`Color over Lifetime`（Start Color → End Color 渐变并在末段约 40% 寿命内淡出）与 `Size over Lifetime`（线性缩到 0）可独立开关；
- **渲染**：billboard 精灵（实例化四边形：逐实例只上传粒子中心与归一化寿命，颜色渐变/淡出/尺寸衰减在着色器内完成），默认程序化软圆点，可在 Renderer 里换成图片贴图（内置图片 / 项目 png、jpg、webp 等；贴图 RGB 与粒子颜色相乘、alpha 相乘，白底透明 PNG 即"着色精灵"；缺失或加载失败回退软圆点）；`Additive`（叠加，火焰/魔法）或 `Normal`（透明混合，烟雾/雨雪）；粒子跟随节点的渲染层，相机 Culling Mask 排除该层时一同排除；构建导出会自动把粒子引用的贴图一并打包；
- **上限**：`Max Particles` 为同时存活上限（缓冲容量），到上限后**轮转覆盖最旧的粒子**（发射不断流）；
- **渲染后端**：WebGL 与 WebGPU 两种后端下粒子外观一致（后端只决定材质实现——GLSL / TSL 节点材质，几何与缓冲布局相同）；由于 WebGPU 的原生点图元固定 1 像素，粒子统一用实例化四边形绘制，因此也不再受点尺寸上限裁剪；
- 视口中以火花图标标示发射器位置（预览/构建不显示图标，只回放粒子）；播放/暂停/停止/重启为运行时控制，不写入场景文件；脚本可经 SDK `ParticleSystemNode` / `engine.particles` 控制。

## 阴影（投影）

阴影由**各灯自带**，不设独立节点：

1. **投射**：点光源 / 平行光 / 聚光灯的检查器卡片把 **Shadow 类型**选为 `Hard`（硬阴影）或 `Soft`（柔和阴影）（环境光无阴影；`Off` = 不投影）。三种灯各自的实现——平行光用正交阴影相机（自动按场景包围盒后推贴合，灯站在场景里也不会裁掉近侧阴影）、聚光灯用透视阴影相机（远平面按场景贴合）、点光源用立方体阴影贴图（六个 90° 面，贴图降为 1024 档控制开销）；
2. **阴影参数**：勾选后可调 `Strength`（浓度 0~1）、`Bias`（深度偏移，压制自阴影麻点）、`Normal Bias`（法线偏移，0 = 自动按阴影贴图纹素相对化）、`Near Plane`（近裁剪面，比这更近的物体不参与投影）；
3. **接收**：网格（基元与模型）默认投射 + 接收阴影。想让影子落在"地面"上，加一块 Plane 网格（或任何网格）即可。

阴影贴图分辨率（点光 1024 / 其余 2048）、深度与法线偏移的自动档由引擎按阴影范围置位；物体增删、拖动、缩放后阴影相机范围自动跟上，不会出现"阴影被裁掉一半"。阴影软化半径 1~5（Hard = 1，Soft = 4）。

## 渲染层级与标签

标签与层在 **项目设置 › 标签与层** 维护：

- **层（Layer）**：最多 32 个（three.js 渲染管线上限），内置层 0 `Default` 不可删；节点在检查器 Node 卡单选所属层（写入应用到对象子树），非 0 层才写入场景文件（旧场景天然兼容，引用了已删层的节点回退显示 Layer N）；
- **相机 Culling Mask**：只渲染掩码内层的对象。编辑器自由视角恒全层可见（避免编辑时对象凭空消失），预览激活相机节点或网页运行时按掩码裁剪；
- **灯光 Culling Mask**：只照亮掩码内层的对象（灯光节点与灯光组件都有）。three.js 的灯光是整帧全局的，这里按「在用层」自动拆多次渲染 pass 实现——相机掩码全开或场景只占用一层时单 pass，零额外开销；被灯的掩码排除的层，该灯的投影也不参与（阴影相机层同步）；
- **被裁剪 ≠ 不存在**：对象不渲染但仍参与物理/脚本/动画；
- **标签（Tag）**：节点的字符串标识（内置 `Untagged` = 空串），检查器 Node 卡下拉选择（标签列表在 项目设置 › 标签与层 维护）；标签不参与渲染，供脚本 `findByTag` 检索。

## 场景文件格式

场景保存为 `.scene` JSON 文档（了解结构有助于排查外部工具/版本管理中的差异）：

```jsonc
{
  "metadata": { /* 场景元信息 */ },
  "settings": { "rendering": { /* 场景级渲染设置 */ } },
  "root": {
    "type": "node",            // 节点类型键（node/meshNode/pointLightNode/uiCanvasNode…）
    "id": "…",                 // 节点 id（脚本 entity.id 与之一致）
    "name": "Root",
    "parentId": null,
    "childIds": ["…"],         // 子节点 id 列表
    "active": true,
    "visible": true,
    "transform": { "position": {"x":0,"y":0,"z":0}, "rotation": {"x":0,"y":0,"z":0}, "scale": {"x":1,"y":1,"z":1} },
    "properties": { /* 节点附属数据 */ },
    "tag": "enemy",            // 仅非空时写入
    "layer": 2,                // 仅非 0 时写入
    "prefab": "assets/prefabs/x.prefab",  // 仅预制体实例写入
    "components": [            // 仅非空时写入
      { "id": "…", "type": "light", "lightKind": "point", "intensity": 1, "…": "…" },
      { "id": "…", "type": "script", "script": "src/hp.ts", "executionOrder": 0, "props": { "max": 100 } }
    ],
    "children": [ /* 子节点（同结构递归） */ ]
  }
}
```

约定：

- 各节点类型把**自身特有字段**直接写在节点对象上（如相机节点的 `cameraType/fov/near/far/orthoSize/clearFlags/clearColor/cullingMask`；模型网格节点的动画图 `animGraph` 与骨骼绑定 `boneBindings` 也在节点对象上）；
- 组件以 `components` 数组挂载，`type` 区分（light / audioSource / rigidBody / collider / animationClip / script 等），脚本组件以 `script` 相对路径引用 `src/**.ts`，属性覆盖存 `props`；
- `executionOrder` 为 0、`tag` 为空、`layer` 为 0 时**缺省不写**（保持旧场景文件字节兼容）；
- 加载时对全部字段做收敛解析（非法值回默认），旧版本场景可无损打开。

## 撤销与保存

- 场景修改（添加/删除/移动/属性编辑/变换/组件增删/预制体操作）均进入撤销历史，Ctrl+Z 或工具栏「撤销」回退；
- 撤销粒度为整节点快照：多选批量操作只算一步；
- Ctrl+S 或「保存」把当前场景写入场景文件；有未保存修改时保存按钮带圆点标记，关闭项目时提示保存。
