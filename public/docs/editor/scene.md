# 场景编辑

## 层级面板

左/右停靠区的「层级」面板以树状展示场景全部节点。

- **选中**：单击选中；Ctrl/Cmd+点击 多选切换；Shift+点击 范围多选；
- **搜索**：顶部搜索框按名称过滤（搜索时忽略折叠状态）；
- **折叠/展开**：点击箭头折叠子树；拖拽悬停折叠节点时自动展开；
- **可见性**：行尾小眼睛切换显示/隐藏（隐藏时同时取消激活，再点恢复）；
- **添加节点**：右键节点（或空白处「添加到根节点」）> 添加节点，子菜单见下；
- **重命名**：右键「重命名」或 F2；
- **预制体**：右键「存储为预制体…」把子树存为 `.prefab` 资产；预制体实例右键「更新预制体」回写资产；
- **删除**：右键「删除」（根节点不可删除/重命名）；
- **拖拽移动**：按住行拖拽，松开时按落点位置选择 上方 / 内部（成为子级）/ 下方；拖入自身子树被拒绝；支持多选整体拖动。

## 可创建的节点类型

右键「添加节点」菜单：

| 分组 | 类型 |
| --- | --- |
| 网格 | Box / Sphere / Plane / Cylinder / Cone / Torus / Capsule（基元由几何注册表驱动） |
| 灯光 | Point Light / Directional Light / Spot Light / Ambient |
| 相机 | Camera |
| 空组 | Group |
| 音频 | Audio Source |
| 粒子 | Particle System（粒子发射器，见下文） |
| 天空盒 | Procedural Skybox（程序化天空）/ Cube Skybox（立方体贴图） |
| 脚本节点 | 由脚本 `@nodeType` 声明的类型（有声明时出现） |

模型资产经资产面板「添加到场景」或拖入创建为模型网格节点。

## 粒子系统

Particle System 节点是场景中的粒子发射器（Unity ParticleSystem 语义子集），入图即在视口中实时模拟，参数改动实时生效：

- **发射方向**：Cone / Box 沿节点**本地 -Z** 发射（与灯光、相机的前向一致），旋转节点即改变喷射方向；Sphere / Hemisphere 由球心向外；
- **模拟空间**：`Local` 粒子跟随节点移动（火把/引擎尾焰），`World` 粒子留在世界空间（烟迹/拖尾）；
- **循环与预热**：循环系统持续发射；非循环系统发射 `Duration` 秒后停止，粒子全部消亡即播完（检查器 ▶ 可重播）；`Prewarm` 让循环系统入图/重启时快进一个周期，粒子瞬间就位；
- **随寿命变化**：`Color over Lifetime`（Start Color → End Color 渐变并在末段淡出）与 `Size over Lifetime`（线性缩到 0）可独立开关；
- **渲染**：billboard 精灵，默认程序化软圆点，可在 Renderer 里换成图片贴图（内置图片 / 项目 png、jpg、webp 等；贴图 RGB 与粒子颜色相乘、alpha 相乘，白底透明 PNG 即"着色精灵"；缺失或加载失败回退软圆点）；`Additive`（叠加，火焰/魔法）或 `Normal`（透明混合，烟雾/雨雪）；粒子跟随节点的渲染层，相机 Culling Mask 排除该层时一同排除；构建导出会自动把粒子引用的贴图一并打包；
- **上限**：`Max Particles` 为同时存活上限（缓冲容量），到上限后新粒子等待旧粒子消亡；
- 视口中以火花图标标示发射器位置（预览/构建不显示图标，只回放粒子）；播放/暂停/停止/重启为运行时控制，不写入场景文件；脚本可经 SDK `ParticleSystemNode` / `engine.particles` 控制。

## 阴影（投影）

阴影由**各灯自带**（Unity 的 Light → Shadows 语义），不设独立节点：

1. **投射**：点光源 / 平行光 / 聚光灯的检查器卡片把 **Shadow 类型**选为 `Hard`（硬阴影）或 `Soft`（柔和阴影）（环境光无阴影；`Off` = 不投影）。三种灯各自的实现——平行光用正交阴影相机（自动按场景包围盒后推贴合，灯站在场景里也不会裁掉近侧阴影）、聚光灯用透视阴影相机（远平面按场景贴合）、点光源用立方体阴影贴图（六个 90° 面，贴图降为 1024 档控制开销）；
2. **阴影参数**：勾选后可调 `Strength`（浓度 0~1）、`Bias`（深度偏移，压制自阴影麻点）、`Normal Bias`（法线偏移，0 = 自动按阴影贴图纹素相对化）、`Near Plane`（近裁剪面，比这更近的物体不参与投影）；
3. **接收**：网格（基元与模型）默认投射 + 接收阴影。想让影子落在"地面"上，加一块 Plane 网格（或任何网格）即可。

阴影贴图分辨率（点光 1024 / 其余 2048）、深度与法线偏移的自动档由引擎按阴影范围置位；物体增删、拖动、缩放后阴影相机范围自动跟上，不会出现"阴影被裁掉一半"。

## 渲染层级与标签

Unity Tags and Layers 语义，标签与层在 **项目设置 › 标签与层** 维护：

- **层（Layer）**：最多 32 个（three.js 渲染管线上限），内置层 0 `Default` 不可删；节点在检查器 Node 卡单选所属层，非 0 层才写入场景文件（旧场景天然兼容，引用了已删层的节点回退显示 Layer N）；
- **相机 Culling Mask**：只渲染掩码内层的对象。编辑器自由视角恒全层可见（避免编辑时对象凭空消失），预览激活相机节点或网页运行时按掩码裁剪；
- **灯光 Culling Mask**：只照亮掩码内层的对象（灯光节点与灯光组件都有）。three.js 的灯光是整帧全局的，这里按「在用层」自动拆多次渲染 pass 实现——相机掩码全开或场景只占用一层时单 pass，零额外开销；被灯的掩码排除的层，该灯的投影也不参与（阴影相机层同步）；
- **被裁剪 ≠ 不存在**：对象不渲染但仍参与物理/脚本/动画；
- **标签（Tag）**：节点的字符串标识（内置 `Untagged` = 空串），检查器 Node 卡下拉选择（标签列表在 项目设置 › 标签与层 维护）；标签不参与渲染，供脚本 `findByTag` 检索。


## 视口

中央 3D 视口：

- **选择**：左键点击节点（点击空白取消选中；根节点不可从视口选中）；
- **变换工具**：顶部工具条 移动 (W) / 旋转 (E) / 缩放 (R)，拖拽 Gizmo 变换；
- **坐标系**：本地（对象自身轴）/ 世界（场景固定轴）切换；
- **轨道漫游**：右键/中键拖拽旋转视角，滚轮缩放；
- **对齐到当前视口**：层级面板右键相机节点 > 「对齐到当前视口」，把该相机节点的位姿与取景参数写为当前视口相机的观察角度（透视相机同步视场角 fov，正交相机按当前取景范围折算正交半高）；适合摆好构图后一键落位相机，一次撤销可还原；
- **预览渲染**：视口可切换用场景相机节点取景渲染（相机辅助线、网格等编辑辅助物同步隐藏）；
- 辅助物：地面网格、相机盒体与视锥线框（按设计分辨率）、灯球、gizmo、选择框；**灯光辅助线仅选中该灯时显示**——点光 = 范围环（半径随 Range，Range=0 无限远时收拢隐藏）、聚光 = 光锥（底圆 + 四条斜线，长度随 Range、半径随 Spot Angle，Range=0 时收拢隐藏）、平行光 = 方向箭头。

## 变换语义

- 位置/缩放：米制；旋转：度制欧拉角 XYZ；
- 检查器与脚本共享同一套变换语义（脚本侧 `entity.rotate` 等均为度）。

## 撤销与保存

- 场景修改（添加/删除/移动/属性编辑/变换）均进入撤销历史，Ctrl+Z 或工具栏「撤销」回退；
- Ctrl+S 或「保存」把当前场景写入场景文件；有未保存修改时保存按钮带圆点标记，关闭项目时提示保存。
