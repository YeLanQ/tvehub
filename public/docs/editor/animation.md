# 动画编辑器

底部停靠区的「动画」面板编辑**关键帧动画剪辑**（`.anim` 资产）：为选中节点的属性（位移/旋转/缩放等，按节点能力提供）创建通道与关键帧。

进入方式：选中节点后打开动画面板，顶部选择/新建要编辑的 `.anim` 剪辑。编辑时进入**聚焦模式**：层级高亮目标子树、其它节点置灰，避免误选；面板顶栏出现「退出编辑」按钮。

## 工作流程

1. 选中节点 → 动画面板顶部选择 `.anim` 剪辑（没有就先在资产面板右键「新建动画」，或给节点添加「动画剪辑」组件后从组件卡打开）；
2. 「＋ 添加属性」为剪辑添加可动画通道（按节点能力列出）；
3. 拖动时间轴到目标时刻 → 点通道行的 **K** 键落关键帧（取节点当前值），或移动节点后按 **K 全部**；
4. 也可以开 **● 录制**：直接在视口里摆姿势，变换一变即自动 K 帧；
5. 切到**曲线编辑**视图微调插值与切线；
6. ▶ 播放预览（只作用于选中节点），满意后经节点的「动画剪辑」组件在预览/发布中播放。

剪辑改动自动防抖落盘（约 0.6s），顶部显示 保存中… / 未保存 / 已保存 状态。

## 顶部工具条

| 控件 | 说明 |
| --- | --- |
| 剪辑选择 | 选择/新建要编辑的 `.anim` 剪辑 |
| 时长 | 剪辑时长（秒，≥0.1；缩短后播放头自动钳回范围内） |
| 循环 | 循环播放 |
| ●（录制） | 开启后修改节点变换自动 K 帧（对已添加通道，变化阈值 0.0001）；播放/停止会自动关闭录制 |
| ▶ / ⏸ / ⏹ | 播放预览（应用到选中节点）/ 暂停 / 停止并还原节点姿势；非循环播放到末尾自动停止并还原 |
| 时间吸附 | scrub 与关键帧拖拽对齐到刻度细分网格（按住 Alt 临时关闭） |
| K 全部 | 为所有已添加通道在当前时间 K 帧（取选中节点当前值） |
| ＋ 添加属性 | 为剪辑添加可动画属性 |
| 视图模式 | 帧动画关键帧轨道（dope）/ 单通道曲线编辑（curve） |
| 值×缩放滑条 / 适配 | 曲线模式专用：数值轴缩放（0.2~4×）/「适配」一键适配全曲线 |

时间显示 `当前 / 时长`（秒）；目标节点未选中时提示「（未选中节点）」。

## 通道（左列）

- 「＋ 添加属性」按选中节点能力列出可动画属性（分组菜单，见下表）；
- 通道树按属性路径分组显示（如 `Transform › Position › X`），组可折叠——折叠时轨道区显示子通道关键帧的**合并概要**；
- 每叶子行：**K**（当前时间 K 帧）、**✕**（移除通道连同关键帧）、点选通道名进入曲线视图；标题显示关键帧数量；
- 新通道创建时自动在 0s 与当前时间各落一帧（取节点当前值），立刻有动画可看；
- 已添加的通道在菜单中禁用（不重复添加）。

### 可动画属性目录

| 分组 | 通道 | 适用节点 |
| --- | --- | --- |
| 变换 | 位置 X/Y/Z、旋转 X/Y/Z、缩放 X/Y/Z（共 9 条） | 全部节点 |
| 灯光 | 灯光强度 `light.intensity` | 灯光节点 |
| 材质 | 颜色 R/G/B、金属度、粗糙度、自发光强度 | 基元网格（有材质） |

通道键即 `.anim` 文档里的 `prop` 字符串（`"position.x"` / `"light.intensity"` / `"material.metalness"` 等）；旋转通道为度制。

## 帧动画轨道（右侧）

- **关键帧菱形块**：按下即选中；左键拖拽改时间（3px 死区）；右键菜单操作（见下）；
- **标尺**：左键拖拽播放头（scrub）；刻度步长自适应缩放（0.01~60s）；
- **缩放/平移**：滚轮缩放时间轴（以指针时刻为锚）、Ctrl+滚轮平移、Shift+滚轮横滚、中键拖拽平移（1× 全览时水平拖到边界自动放大一级）；
- **吸附**：scrub 与关键帧拖拽对齐到刻度步长的 1/10 网格（「吸附」开关默认开，按住 Alt 临时关闭）；
- 组行折叠时显示子通道关键帧合并概要。

### 关键帧右键菜单

| 菜单 | 说明 |
| --- | --- |
| 平滑（自动切线）/ 线性 / 阶跃 | 三种插值切换 |
| 切线对称（联动）/ 切线断开（独立）/ 切线压平（水平） | 手动切线的联动方式 |
| 删除关键帧 | 移除该帧（红色项） |

## 曲线编辑

- 点选通道名显示其曲线；点空白处插帧（点击即落帧）；拖关键帧同时改 时间/数值（钳回可视窗内）；
- **切线手柄**：自动切线态显示虚影（拖动即固化为手动切线）；手动态为实线可拖（拖动手柄强制该段为平滑插值，对称联动时另一侧镜像）；手柄长度 = 权重（可编辑）；
- **数值轴缩放**（1 = 自动适配全曲线，含鼓包与播放头采样）、「适配」复位、中键拖拽可同时平移时间窗与数值窗；
- 选中关键帧后底部操作条：插值下拉（平滑·自动切线 / 线性 / 阶跃）+「删除 K」按钮。

### 插值方式

| 方式 | 行为 |
| --- | --- |
| 线性 linear | 两帧间直线过渡 |
| 阶跃 step | 保持本帧值直到下一帧（瞬变/开关类） |
| 平滑 smooth | 三次 Hermite 样条；默认**自动切线**（Catmull-Rom，支持非均匀帧距），可被手动切线覆盖 |

## 录制模式

开启 ● 后以当前值为基线，逐帧比对选中节点各通道的值，变化超过阈值即在当前时间**自动 K 帧**——工作方式类似传统三维软件的 auto-key：先在时间轴选好时刻，再到视口摆姿势。

## `.anim` 文件格式

剪辑保存为 JSON（了解结构有助于外部工具处理与版本管理）：

```jsonc
{
  "type": "animclip",
  "name": "My Clip",
  "duration": 3.0,           // 秒（0.1..3600）
  "loops": true,
  "curves": [
    {
      "prop": "position.y",  // 通道键（见上文目录）
      "keys": [
        { "t": 0.0, "v": 0.0, "i": "smooth", "ti": -0.5, "to": 0.5, "tm": true },
        { "t": 1.5, "v": 2.0, "i": "linear" }
      ]
    }
  ]
}
```

- 关键帧字段：`t` 秒、`v` 数值、`i` 到下一帧的插值（linear/step/smooth）；`ti`/`to` 为手动入/出切线斜率（缺省 = 自动 Catmull-Rom）、`tm` 两侧联动、`wi`/`wo` 手柄权重（仅编辑器显示/拖拽用，播放求值忽略）；
- 关键帧区间外钳制到端点值；加载时非法关键帧剔除、按时间排序；
- 播放侧（预览/构建产物）按同一格式采样：循环 = 时间对时长取模，非循环钳制；`speed` 倍速、`stop` 回采 0 秒姿势。

## 运行

- `.anim` 剪辑经节点上的「动画剪辑 Animation Clip」组件绑定播放（检查器配置或脚本 `AnimationClip` 门面）；
- 通道只覆盖剪辑中存在的属性（只 K 了 `position.x` 就只驱动 x 轴，其余轴不受影响）；
- 材质通道作用于对象材质（颜色分量为 0~1），灯光通道作用于节点子树内首个灯光；
- 模型内嵌骨骼动画不支持本编辑器制作，经「Animation」卡片的动画图编辑（见[检查器与组件](inspector.md)）。

## 骨骼与皮肤调试（Animation 卡片）

选中含骨骼或形态键的模型网格时，「Animation」卡片底部出现**皮肤**调试区（对应 three 官网 `animation/skinning` 系列示例的交互）。全部为**运行时调试控制，不随场景保存**（「绑定」除外）；脚本可在预览/发布中经 `SkeletalAnimation` 门面完成同样的事（见 [SDK 组件](../sdk/components.md)）。

| 区域 | 交互 |
| --- | --- |
| 显示骨骼 | 强制常显骨骼辅助线（不必选中节点）；「复位姿势」把全部骨骼恢复到加载姿势 |
| 骨骼 | 顶部搜索框按子串**查找骨骼 / IK**（命中 IK 直接可选为绑定目标）；骨骼树（点击展开/选中），选中后编辑本地位移/旋转（度）/缩放，或复位该骨骼 |
| 形态键 | 每网格分组的权重滑块（0..1），拖动即时生效（表情/口型等 morph target） |
| 动作权重 | 每剪辑权重滑块（叠加混合多个动作）、「加法」开关（以差值叠加层播放）、「1×」一次性播放（定格末帧后自动回落基础动作） |
| IK | 脚本 `addIK` 注册的 IK 链列表：启停 / 移除 |
| 绑定 | 把场景节点绑到骨骼/IK 目标上每帧跟随（官方 ik 示例挂点语义）：选目标节点 + 骨骼/IK（骨骼树选中自动联动）→「添加绑定」；列表可解除。选项：保持偏移（attach 时刻相对位姿）/ 跟随旋转（关闭则仅位置跟随）。**绑定随场景保存**（节点 boneBindings 数据，可撤销），预览/发布同样生效 |

说明：

- 动作权重为**叠加**语义：拖动滑块即可让多个动作同时按权重混合（如 0.6 走路 + 0.4 跑步）；「播放/停止」按钮管理的当前剪辑与权重层相互独立，「停止」清空全部层；
- 「加法」层需模型剪辑本身适合做差值叠加（姿态类剪辑）；播放时先经 `makeClipAdditive` 转换（惰性缓存）；
- 骨骼/形态键/权重的编辑在动作播放中会被动画覆写（被驱动部分），建议暂停后编辑，或用于 IK/朝向这类每帧覆写场景。
