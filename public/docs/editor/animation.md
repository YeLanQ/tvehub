# 动画编辑器

底部停靠区的「动画」面板编辑**关键帧动画剪辑**（`.anim` 资产）：为选中节点的属性（位移/旋转/缩放等，按节点能力提供）创建通道与关键帧。

进入方式：选中节点后打开动画面板，顶部选择/新建要编辑的 `.anim` 剪辑。编辑时进入**聚焦模式**：层级高亮目标子树、其它节点置灰，避免误选。

## 顶部工具条

| 控件 | 说明 |
| --- | --- |
| 剪辑选择 | 选择/新建要编辑的 `.anim` 剪辑 |
| 时长 | 剪辑时长（秒） |
| 循环 | 循环播放 |
| ●（录制） | 开启后修改节点变换自动 K 帧（对已添加通道） |
| ▶ / ⏸ / ⏹ | 播放预览（应用到选中节点）/ 暂停 / 停止并还原节点姿势 |
| 时间吸附 | scrub 与关键帧拖拽对齐到刻度细分网格（按住 Alt 临时关闭） |
| K 全部 | 为所有已添加通道在当前时间 K 帧（取选中节点当前值） |
| ＋ 添加属性 | 为剪辑添加可动画属性 |
| 视图模式 | 帧动画关键帧轨道 / 单通道曲线编辑（二选一显示） |

## 通道（左列）

- 「＋ 添加属性」按选中节点能力列出可动画属性（如 position/rotation/scale 各轴）；
- 每通道行：K（当前时间 K 帧）、移除通道、点选通道名进入曲线视图；标题显示关键帧数量。

## 帧动画轨道（右侧）

- 关键帧菱形块：按下选中、拖拽改时间、右键菜单操作；
- 组行折叠时显示子通道关键帧合并概要；
- 时间轴缩放（1× 铺满）：滚轮缩放、Ctrl+滚轮平移、中键拖拽平移。

## 曲线编辑

- 点选通道名显示其曲线；数值轴缩放（1 = 自动适配全曲线）、「适配」复位；
- 选中关键帧后底部操作条：插值方式（线性 / 阶跃 / 平滑；自动 = 平滑 + Catmull-Rom 自动切线）、删除 K。

## 运行

- `.anim` 剪辑经节点上的「动画剪辑 Animation Clip」组件绑定播放（检查器配置或脚本 `AnimationClip` 门面）；
- 模型内嵌骨骼动画不支持本编辑器制作，经「Animation」卡片的动画图编辑（见[检查器与组件](inspector.md)）。

## 骨骼与皮肤调试（Animation 卡片）

选中含骨骼或形态键的模型网格时，「Animation」卡片底部出现**皮肤**调试区（对应 three 官网 `animation/skinning` 系列示例的交互）。全部为**运行时调试控制，不随场景保存**；脚本可在预览/发布中经 `SkeletalAnimation` 门面完成同样的事（见 [SDK 组件](../sdk/components.md)）。

| 区域 | 交互 |
| --- | --- |
| 显示骨骼 | 强制常显骨骼辅助线（不必选中节点）；「复位姿势」把全部骨骼恢复到加载姿势 |
| 骨骼 | 顶部搜索框按子串**查找骨骼 / IK**（命中 IK 直接可选为绑定目标）；骨骼树（点击展开/选中），选中后编辑本地位移/旋转（度）/缩放，或复位该骨骼 |
| 形态键 | 每网格分组的权重滑块（0..1），拖动即时生效（表情/口型等 morph target） |
| 动作权重 | 每剪辑权重滑块（叠加混合多个动作）、「加法」开关（以差值叠加层播放）、「1×」一次性播放（定格末帧后自动回落基础动作） |
| IK | 脚本 `addIK` 注册的 IK 链列表：启停 / 移除 |
| 绑定 | 把场景节点绑到骨骼/IK 目标上每帧跟随（官方 ik 示例挂点语义）：选目标节点 + 骨骼/IK（骨骼树选中自动联动）→「添加绑定」；列表可解除。选项：保持偏移（attach 时刻相对位姿）/ 跟随旋转（关闭则仅位置跟随）。**绑定随场景保存**（节点 boneBindings 数据，可撤销），预览/发布同样生效 |

说明：

- 动作权重为**叠加**语义：拖动滑块即可让多个动作同时按权重混合（如 0.6 走路 + 0.4 跑步）；「播放/停止」按钮管理的当前剪辑与权重层相互独立，「停止」清空全部层；
- 「加法」层需模型剪辑本身适合做差值叠加（姿态类剪辑）；播放时先经 `makeClipAdditive` 转换（惰性缓存）；
- 骨骼/形态键/权重的编辑在动作播放中会被动画覆写（被驱动部分），建议暂停后编辑，或用于 IK/朝向这类每帧覆写场景。
