# 脚本工作台

工具栏切到「脚本」进入脚本工作台：Monaco 标签页编辑器 + 状态栏，保存即写盘并编译。着色器（`.shader`）源码也在这里编辑（同一套标签页体系）。

## 打开与新建

- 资产面板双击 `.ts` 脚本（或 `.shader` 着色器）打开标签页；
- 资产面板 `src/` 目录右键「新建脚本」（基础模板，类名 = 文件名 PascalCase）；
- 资产面板右键「创意工坊 ▸ Code ▸ 原型」按原型新建（任意可编辑目录可调起，脚本固定创建在 `src/` 下并自动打开）；
- 检查器「添加组件 > 脚本」菜单中「新建脚本…」。

新建脚本模板内容：`import { Component, property, nodeType, engine } from "tve"` 头 + 注释掉的 `@nodeType` / `@property` 示例 + 空的 `onStart()`（打印挂载日志）与 `onUpdate(delta)`，类名按文件名自动注入。

## 标签页与状态栏

- 标签页：点击切换；**×** 关闭（有未保存修改时先确认「保存并关闭 / 放弃修改」）；页签带未保存圆点标记；无打开文件时提示如何打开；
- 状态栏（底部）：文件路径 + 状态文案：

| 状态 | 含义 |
| --- | --- |
| 编译失败：… | TS 编译诊断（点击控制台看完整错误；该脚本不参与预览/构建） |
| 有未保存的修改 | Ctrl+S 保存并编译 |
| 已保存 · 编译通过 | 脚本 OK（着色器为「已保存」+ 解析结果） |

## 编辑与保存

- **Ctrl+S** 保存当前脚本 = 写盘 + 内存编译 + 解析属性声明（产物不落盘，预览/构建时按编译产物注入）；
- 保存后检查器立即刷新该脚本的属性控件（含刚加的 `@property`）；
- 关闭有未保存修改的标签页时提示保存；
- 工具栏「保存」（Ctrl+S）会一并保存脚本工作台中的脏脚本；
- 着色器保存会同步 Shader 指令名到资产路径、重新解析并即时刷新视口（见[着色器与自定义效果](shaders.md)）。

## 智能提示

- 编辑器加载 SDK 类型契约（`tve.d.ts`），`import { Component, property, engine } from "tve"` 即可获得完整的自动补全与类型检查（契约以虚拟包 `tve` 注入，无需配置路径）；
- Monaco 开箱可用：命令面板（F1）、查找替换、F12 跳转、F2 重命名符号、快速修复、括号配对着色、行高亮；
- 编译选项：ES2020 目标 + strict + 实验性装饰器（支持 `@property` / `@nodeType`）；
- 跨脚本组件引用用 `import type` 只引入类型（见[装饰器 › 用户脚本类字段](../sdk/decorators.md)）；
- `.shader` 使用内置 GLSL 语法高亮。

## 绑定到节点

- 检查器「添加组件 > 脚本」选择 `src/` 下脚本，卡片中配置属性；
- 或用 `@nodeType` 声明脚本节点，经层级面板「添加节点 > 脚本节点」创建（自动挂载）；
- 入口脚本在 项目设置 → 基础信息 中设置，随预览/发布挂在场景根节点。

## 脚本编写规范

- 默认导出一个继承 `Component` 的类（导出其他内容不会被当作组件）；
- `@property` 声明可编辑属性（检查器渲染控件）；字段初值即默认值；
- 生命周期钩子：`onEnable` / `onStart` / `onUpdate` / `onCollisionEnter` / `onCollisionExit` / `onDisable` / `onDestroy`（全部可选）；
- 详细 API 见 [SDK 文档](../sdk/overview.md)。

## 编译说明

- TS → ES2020 ESM 转译（内存编译、**产物不落盘**）；`"tve"` 导入说明符自动重写为引擎运行时模块，无需手动配置路径；
- 编译器还会扫描默认导出类的组件类型字段（`anim!: AnimationClip` / `follow!: CameraFollow`），注入运行时元数据供自动绑定（见 [SDK 装饰器](../sdk/decorators.md)）；
- 属性解析**不执行用户代码**：装饰器字段与旧式 `static props` 声明均被静态解析供检查器渲染；
- 单个脚本编译失败只影响该脚本（不参与预览/构建，其他脚本正常），错误在控制台与状态栏提示；同一路径的失败在控制台只报一次；
- 编译范围固定为 `src/**.ts`；脚本重命名/删除会同步改写场景内脚本组件的引用。

## 调试

- `engine.log / warn / error` 输出到编辑器控制台（预览运行时），发布产物输出到浏览器控制台；
- 报错隔离：单个脚本抛错只停用该实例，不影响其他脚本（见 [SDK 总览 › 执行顺序与错误隔离](../sdk/overview.md)）；
- 预览页签的 console 转发（`[预览]` 前缀）可看到运行时全部输出；
- 想断点调试可用「在浏览器打开」预览页，用浏览器 DevTools 直接调试编译产物。
