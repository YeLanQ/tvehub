# 脚本工作台

工具栏切到「脚本」进入脚本工作台：Monaco 标签页编辑器 + 状态栏，保存即写盘并编译。

## 打开与新建

- 资产面板双击 `.ts` 脚本打开标签页；
- 资产面板 `src/` 目录右键「新建脚本」（基础模板，类名 = 文件名 PascalCase）；
- 资产面板右键「创意工坊 ▸ Code ▸ 原型」按原型新建（任意可编辑目录可调起，脚本固定创建在 `src/` 下并自动打开）；
- 检查器「添加组件 > 脚本」菜单中「新建脚本…」。

## 编辑与保存

- **Ctrl+S** 保存当前脚本 = 写盘 + 内存编译 + 解析属性声明（产物不落盘，预览/构建时按编译产物注入）；
- 状态栏显示：编译失败原因 / 有未保存的修改（Ctrl+S 保存并编译）/ 已保存 · 编译通过；
- 关闭有未保存修改的标签页时提示保存；
- 工具栏「保存」（Ctrl+S）会一并保存脚本工作台中的脏脚本。

## 智能提示

编辑器加载 SDK 类型契约（`tve.d.ts`），`import { Component, property, engine } from "tve"` 即可获得完整的自动补全与类型检查；跨脚本组件引用用 `import type` 只引入类型。

## 绑定到节点

- 检查器「添加组件 > 脚本」选择 `src/` 下脚本，卡片中配置属性；
- 或用 `@nodeType` 声明脚本节点，经层级面板「添加节点 > 脚本节点」创建（自动挂载）；
- 入口脚本在 项目设置 → 基础信息 中设置，随预览/发布挂在场景根节点。

## 脚本编写规范

- 默认导出一个继承 `Component` 的类；
- `@property` 声明可编辑属性（检查器渲染控件）；字段初值即默认值；
- 生命周期钩子：`onEnable` / `onStart` / `onUpdate` / `onCollisionEnter` / `onCollisionExit` / `onDisable` / `onDestroy`（全部可选）；
- 详细 API 见 [SDK 文档](../README.md)。

## 编译说明

- TS → ES2020 ESM 转译；`"tve"` 导入说明符自动重写为引擎运行时模块，无需手动配置路径；
- 单个脚本编译失败只影响该脚本（不参与预览/构建），错误在控制台与状态栏提示；
- 属性解析不执行用户代码：装饰器字段与旧式 `static props` 声明均被静态解析供检查器渲染。
