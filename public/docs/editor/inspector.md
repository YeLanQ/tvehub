# 检查器与组件

右侧停靠区的「属性」（检查器）面板编辑选中节点/资产。面板由若干组件卡片组成，卡片可折叠；卡片标题栏带启用/停用开关，⋮菜单支持 上移/下移（执行顺序）、重置、移除等操作。

## 面板模式

检查器按优先级显示三种内容：

1. **资产模式**：资产面板最后点击了某资产 → 显示该资产的属性（材质参数、着色器源码编辑、预制体等，按扩展名分面板）；
2. **多选批量卡**：选中 ≥2 个节点 → 显示多重编辑视图（见下文）；
3. **节点检查器**：单选节点 → 按挂载顺序排列全部组件卡片。

无选中显示「未选择节点」。

**多选批量卡**：头部列出选中节点（最多 6 个名称）；可统一编辑 标签、层、激活/可见（不一致时显示混合态）、位置/旋转/缩放（混合值以「混合」徽标提示，编辑 = 绝对值应用到全部）；底部「＋ 批量添加组件」一次给全部选中节点挂组件。整批操作为一条撤销记录。

**卡片通用交互**：数值输入框支持拖动调节（Shift = 1/10 精细）与点击键盘输入；停用组件时卡体显示「组件已停用」并变暗。

## 节点通用卡片

| 卡片 | 内容 |
| --- | --- |
| Node | 名称、层（渲染层级单选，选项来自项目层表）、标签（项目标签下拉，内置 Untagged；旧值不在列表时保留显示）、可见；预制体实例显示来源资产路径 |
| Transform | 本地 位置/旋转/缩放（旋转为度制欧拉角，步进 0.25°） |

UI 节点没有 3D Transform 卡，换成 **2D Transform + 锚点卡**（见 [UI 系统](ui.md)）。

## 网格节点（meshNode）

| 卡片 | 内容 |
| --- | --- |
| Mesh | 基元网格：几何类型下拉（box/sphere/plane/cylinder/cone/torus/capsule）；模型网格：模型资产下拉（内置模型/项目模型两组，支持导入 glb/gltf/fbx/obj） |
| Material | 材质资产选择 + 着色器切换（PBR/Unlit/卡通）+ 参数编辑（内置材质只读，可复制为项目材质后编辑）；着色器的 Properties 参数一并呈现（详见[材质参数](assets.md)） |

## 灯光节点

Light 卡片：

| 分组 | 字段 |
| --- | --- |
| 类型 | 点光/平行光/聚光/环境光（切换即重建） |
| 通用 | 颜色（0xRRGGBB）、强度（≥0.01）、Culling Mask（只照亮掩码内层；下拉菜单 Everything/Nothing/逐层勾选，勾满自动存 Everything） |
| 点光/聚光 | 照射距离 Range（0.01~10000，0 = 无限远）、衰减指数 Decay（0~10） |
| 聚光 | 光束半角 Spot Angle（0.1~89.9°）、边缘柔和度 Penumbra（0~1） |
| 阴影 | Shadow 类型三档 `Off` / `Hard` / `Soft`；参数组：Strength 浓度（0~1）、Bias 深度偏移（-0.05~0）、Normal Bias 法线偏移（0 = 自动）、Near Plane 近裁剪面、Resolution 分辨率（Auto/512/1024/2048/4096；Auto = 平行光/聚光 2048、点光 1024） |

三种灯各自的阴影实现见「场景编辑 › 阴影」。

## 相机节点

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 相机类型 | 透视（fov 取景）/ 正交（orthoSize 取景）；切换保留另一类型的参数 | 透视 |
| Culling Mask | 只渲染掩码内层的对象；编辑器自由视角恒全层可见，预览激活该相机（或运行时）生效。逐层勾选，含 Everything / Nothing 快捷档 | 全部 |
| 清除标志 | 天空盒（默认）/ 纯色（附取色器）/ 仅深度 / 仅颜色 | 天空盒 |
| 视场角 fov | 1–170 度（透视） | 50 |
| 正交半高 orthoSize | 取景高度的一半，世界单位（正交） | 5 |
| 近/远裁剪面 | near ≥ 0.01、far ≥ 1 | 0.1 / 20 |

运行时相机选择规则见「场景编辑 › 运行时相机选择」。

## 天空盒节点

类型（程序化天空 / 立方体，创建后固定）、材质资产选择（内置材质 + 项目材质）、内置材质显示「复制到项目材质」按钮。天空的全部表现都在**天空盒材质**中编辑：

- 程序化天空材质：太阳（sunDisc 日轮开关 / sunSize 大小 / sunStrength 强度 / sunElevation 仰角 / sunRotation 方位角）、大气（air / dust / ozone 三系数）、altitude 海拔（米）、强度 strength、多重散射 ms 开关等；
- 立方体贴图材质：cubeMap（.texcube 资产）、rotation、strength、worldOpacity、blur 等。

## 音频节点

Audio 卡片：

| 分组 | 字段 |
| --- | --- |
| 资产 | 音频源下拉（内置/项目音频） |
| 播放 | 自动播放、循环（未绑定音频时禁用） |
| 参数 | 音量 0~1、倍速 0.1~4、空间化 2D/3D；3D 时附 参考距离/最大距离/衰减系数 |
| 运行时 | ▶/⏸/⏹ 控制（不落盘）+ 状态文案（未绑定音频/加载中/播放中/已暂停/就绪） |

音源节点与「音源组件」共用同一套卡片字段与语义。

## 粒子系统节点

Particle System 卡片（常规粒子系统语义子集；每项改动一次撤销，实时生效不打断已存活粒子）：

| 分组 | 字段 |
| --- | --- |
| 运行时控制 | ▶ 播放（暂停态续播 / 播完态重播）、⏸ 暂停、⏹ 停止发射（粒子自然消亡）、↻ 重启（清空并从头开始）；状态文案显示存活粒子数。**不落盘** |
| Main | Duration 发射周期（0.05~600s）、Looping、Prewarm（仅循环可用）、Start Delay（0~60s）、Start Lifetime（0.05~120s）、Start Speed（0~200）、Start Size（0.01~100）、Start Color、Gravity 重力系数（-20~20，1 = 9.81；负值上浮）、Simulation Space（Local / World）、Max Particles（1~20000） |
| Emission | Rate over Time（粒子/秒，0~5000） |
| Shape | Shape（Cone / Sphere / Hemisphere / Box）、Radius（0~500）、Angle 圆锥半角（0~89°，仅 Cone） |
| Color over Lifetime | Enabled、End Color |
| Size over Lifetime | Enabled |
| Renderer | Blending（Additive / Normal）、Texture（内置软圆点 / 内置图片 / 项目图片；贴图 RGB 与 Start/End Color 相乘、alpha 相乘，白底透明 PNG 即着色精灵；缺失回退软圆点，资产被删时回显路径并标「未找到」） |

`Max Particles` 与 `Blending` 属于结构参数，改动会重建发射器（粒子从头开始）；其余参数原地更新，换贴图异步加载完成后热替换。切换 Simulation Space 会清空当前粒子。

## UI 节点（画布与 Widget）

UI 画布（渲染模式/设计宽高/Sort Order）与 Widget（文本/图片/按钮/布局容器）的卡片字段、锚点与 2D 变换编辑（100px = 1 单位，位置/尺寸/边距按像素显示）、九宫格锚点预设、缩放适配等详见 [UI 系统](ui.md)。

## 添加组件

检查器底部「添加组件」菜单按分类列出（多实例约束：同一节点不可重复挂载的项会禁用）：

| 分类 | 组件 | 多实例 |
| --- | --- | --- |
| 物理 | 刚体 Rigid Body | 否 |
| 物理 | 碰撞体 Collider | 是 |
| 光照 | 点光源 / 平行光 / 聚光灯 / 环境光 | 否 |
| 音频 | 音源 Audio Source | 是 |
| 动画 | 动画剪辑 Animation Clip | 是 |
| 脚本 | 脚本 Script（选择/新建 `src/` 下脚本） | 是 |

多选批量卡的「批量添加组件」是同款菜单，一次操作应用到全部选中节点（一条撤销记录）。

## 物理

挂了刚体/碰撞体的节点显示 **Physics 模拟控制卡片**：▶ 开始模拟（快照变换，动力学体开始受力）/ ⏸ 暂停 / ⏹ 停止（销毁世界并还原变换）；显示绑定/世界就绪状态（未模拟/已暂停/引擎加载中…/模拟中）。引擎/重力/启用开关在 项目设置 → 物理。无刚体的碰撞体 = 静态碰撞体；运动学体由节点变换/动画驱动。模拟在固定步长 1/60s 下步进；停止模拟从快照还原变换（不写节点数据，撤销历史零污染）。

### 刚体 Rigid Body

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 形态 mode | static（静态）/ kinematic（运动学）/ dynamic（动力学）；dynamic 才显示质量/阻尼/锁定旋转/直立不倒 | dynamic |
| 质量 mass | kg，仅 dynamic 有效（0.001~1e6） | 1 |
| 线性/角阻尼 | linearDamping / angularDamping（≥0） | 0.05 |
| 重力缩放 | gravityScale，0 = 不受重力（非 static 显示） | 1 |
| 连续碰撞检测 ccd | 高速物体防穿透 | 关 |
| 锁定旋转 lockRotation | 碰撞不改变姿态（全冻结），防撞倒 | 关 |
| 直立不倒 upright | 碰撞不翻倒但保留水平旋转（角色类）；与锁定旋转互斥，勾任一自动清另一 | 关 |

### 碰撞体 Collider（可挂多个）

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 形状 shape | box / sphere / capsule / cylinder / convex | box |
| 尺寸来源 autoSize | 开 = 按节点渲染包围盒自动推导（含子树，世界缩放烘入尺寸）；关 = 用显式尺寸 | 开 |
| 显式尺寸 size | box = xyz 边长；sphere 直径取 x；capsule/cylinder 直径取 x、柱高取 y | 1,1,1 |
| 偏移 offset | 相对节点原点的局部偏移（autoSize 时叠加包围盒中心） | 0,0,0 |
| 摩擦系数 friction | 0 = 无摩擦（0~4） | 0.6 |
| 弹性系数 restitution | 0 = 不反弹（0~1） | 0.1 |
| 传感器 isSensor | 只产生触发（onCollisionEnter/Exit）不产生碰撞响应 | 关 |

> 角色类节点建议：刚体摩擦为 0（滑动摩擦力矩会导致自转）＋ 直立不倒或锁定旋转。

## 动画

- 模型网格节点显示 **Animation** 卡片（骨骼动画）：动画模式三档（关闭/单剪辑/动画图）——单剪辑为 剪辑选择、自动播放、倍速（0~10）、循环模式（循环/一次/往复）与 ▶/⏸/⏹ 运行控制；动画图（状态机）为嵌套编辑器——状态（名称 + 绑定剪辑 + 速度/循环）、过渡（from → to + 淡化时长 + 归一化退出时间 + 参数条件）、参数（数值/布尔，改值即时触发过渡）、运行时可查看当前状态并手动切换；
- 含骨骼/形态键的模型在 Animation 卡片底部还有**皮肤调试区**：骨骼树与本地变换编辑/复位、显示骨骼、形态键权重滑块、动作权重混合/加法层/一次性播放、IK 启停（运行时调试，不落盘；详见[动画编辑器](animation.md)）；
- 任意节点可挂 **动画剪辑 Animation Clip** 组件（绑定 `.anim` 资产）：剪辑、自动播放、循环、倍速；关键帧制作见[动画编辑器](animation.md)。

## 脚本组件

挂载 `src/` 下脚本后，卡片显示：

- **脚本路径**（脚本被删时显示「脚本缺失」红标）；
- **执行顺序** NumberField（小者先跑，同序按挂载顺序；与 SDK `executionOrder` 同一字段）；
- **属性控件**按脚本 `@property` / `static props` 声明渲染：

| 声明类型 | 控件 |
| --- | --- |
| number | 数值框（可带 min/max/step） |
| string | 文本框 |
| boolean | 勾选框 |
| color | 取色器 |
| vec3 | 三个数值框 |
| 节点引用 | 场景节点下拉（按声明类型过滤可选节点；空 = 全部） |

- 无属性声明的脚本显示「该脚本未声明属性」；
- 组件引用类字段（`@property(AnimationClip)` 等）不出现在检查器，由运行时自动绑定；
- 「编辑脚本」（⋮菜单）跳转脚本工作台；脚本保存编译后属性控件立即刷新。
