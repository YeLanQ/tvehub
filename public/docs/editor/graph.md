# 场景图

场景图是**另外一种编辑模式**：把层级中的实体拖入画布生成原型卡片，用匹配节点按标签/类型批量圈定目标，用原子操作节点定义预览运行时执行的行为——**不回写编辑器场景**，只在预览/发布产物中作为运行时行为执行。

## 打开场景图

首页（Hub）项目卡片右键 →「打开场景图」，打开一个与编辑器同级的独立窗口（Tauri 窗口 label `graph`）。仅桌面端可用；浏览器环境回退提示。

打开体验与编辑器一致：装载蒙版按阶段汇报「扫描资产 / 打开场景会话 / 装载场景图」后揭幕进入工作区。

## 窗口布局

复用编辑器的停靠系统（同款页签拖拽/浮动/分隔条调宽，布局独立持久化）：

```
┌──────────────────────────────────────────────┐
│ 工具栏：项目信息 · [图|预览] · 撤销 · 重做 · 保存状态 · 窗口控制 │
├─────────┬──────────────────────────┬─────────┤
│ 左停靠区 │         中央工作区           │ 右停靠区 │
│ 层级      │   场景图画布 / 网页预览        │ 检查器    │
│          │                          │ 变量      │
│          │                          │ 自定义    │
├─────────┴──────────────────────────┴─────────┤
│ 底部停靠区：控制台 / 场景                           │
└──────────────────────────────────────────────┘
```

- **左停靠**：层级（与编辑器共享后端场景会话，实时同步）；
- **中央**：图模式 = 场景图画布（Vue Flow）；预览模式 = 网页预览（图上定义的行为在此执行）；
- **右停靠**：检查器 / 变量 / 自定义（三个标签页）；
- **底部停靠**：控制台 / 场景；
- **场景面板**只呈现场景资产（场景文件 + 通往场景的目录）——图与场景一一对应，
  双击场景即切换（层级/实体/场景图随之切换），其余资产类型不在图窗口展示；
- **控制台**与编辑器同源（`ConsolePanel` + `logStore`）：预览运行的引擎日志
  （装配摘要、驱动器采样、告警等，经运行时 `postLog` 通道转发）实时呈现；
- 布局（面板位置 + 各区尺寸 + 浮窗状态）自动持久化，与编辑器布局互不干扰。

### 工具栏

## 场景会话

- 场景会话**按窗口隔离**（后端会话表按 webview 标签分键），与编辑器窗口互不干扰；
- 默认打开项目配置的主场景（空则取第一个场景 → `assets/Main.scene`）；
- 资产面板双击 `.scene` 场景可切换当前场景，层级/实体索引/对应场景的场景图侧车随之切换；
- 编辑器窗口对同一场景的修改**实时同步**到图窗口的层级与实体索引。

## 画布

场景图画布基于 Vue Flow，编辑态以画布数组为权威。四类卡片 + 注释框：

| 卡片 | 来源 | 作用 |
| --- | --- | --- |
| 原型 | 从左侧层级拖入实体生成 | 引用场景实体，属性以场景当前值为参照 |
| 匹配 | 右键添加 | 按标签或类型批量匹配场景实体 |
| 属性读取 | 右键添加 | 把实体自身的某个属性（灯光/材质/脚本等）取成数据值；子级属性先经「获取子级」卡 |
| 操作 | 右键添加 | 原子行为，预览运行时由解释器执行 |
| 注释框 | 工具条/右键添加 | 纯画布元素，标注说明 |

### 画布工具条

| 控件 | 说明 |
| --- | --- |
| 复制 / 粘贴 / 删除 | 选中卡片的剪贴板操作（粘贴时 id 重映射） |
| 注释框 | 在鼠标位置添加注释框 |
| 吸附 | 网格吸附（16px）开关 |
| 适配 | 适配视图（内容包围盒居中） |

### 右键菜单

画布空白处右键：

| 菜单项 | 说明 |
| --- | --- |
| 添加事件 | On Begin / On Tick / On Click（执行链入口） |
| 添加变量节点 | Get 变量（读取）/ Set 变量（写入） |
| 添加控制流 | 分支 / 比较 / For 循环 / ForEach 循环 / While 循环 / 中断开关 |
| 添加数学/工具 | 加减乘除/三角/向量/字符串/插值…（见下文） |
| 添加自定义节点 | 用户定义的节点类型（见下文） |
| 添加匹配（按标签） | 标签匹配节点 |
| 添加匹配（按类型） | 类型匹配节点 |
| 添加操作 | 原子操作子菜单（见下文） |
| 添加注释框 | 同工具条 |
| 粘贴 / 适配视图 | — |

### 连线

双通道连线，按通道配色：

| 通道 | 连接 | 颜色 | 语义 |
| --- | --- | --- | --- |
| 实体集 | 原型/匹配 out → 操作 in | 绿色细线 | 决定操作作用对象，可多入 |
| 执行链 | 操作 next → 操作 exec | 白线+箭头 | 应用时级联下游，单入 |
| 数据引脚 | 数据出 → 数据入 | 青色细线 | 标量/向量数据流动 |

- 入端口唯一：拖到已占用的入引脚 = 替换已有入线（重新连接）；
- 连线按数据类型校验兼容性（见下文）；
- 自环连线被拒绝。

## 节点类型

内置节点分九大类（右键菜单按类别分组）：

### 实体类（entity）

实体集源——为操作节点提供作用对象；属性读取卡把实体属性取成数据值。

| 类型 | 说明 | 端口 |
| --- | --- | --- |
| 原型（entity.proto） | 拖入场景实体生成，按节点 id 精确匹配 | in: 接入（any，可多入）；out: 实体集 |
| 匹配（entity.match） | 按标签或类型批量匹配场景实体 | out: 实体集 |
| 属性读取（entity.prop） | 拉模型读取目标实体的任意属性（通用属性路径，见下文） | in: 实体；out: 值（any） |

- 原型从左侧层级面板拖入画布生成（同实体去重，已存在则提示）；
- 原型「接入」口把实体集/数据传给该实体挂载的**脚本组件**：值变化时回调脚本的 `onGraphInput(value)`（实体集为 `Entity[]`，数据为标量/向量），脚本也可随时轮询 `this.graphInput`；未接线/上游为空时值为 null；
- 匹配节点在检查器设置模式（标签/类型）与模式串（候选来自场景实体），实时显示命中数；
- 属性读取卡在检查器填属性路径（候选列表按上游接入的实体动态生成），「值」引脚连到分支条件 / 比较 / 数学节点等下游数据入引脚；实体集连入时取首个实体。

### 事件类（event）

执行链入口——触发时机固定，有 next（exec 出端口）。

| 类型 | 触发时机 | 说明 |
| --- | --- | --- |
| On Begin（event.onBegin） | 启动时 | 运行时启动时触发一次 |
| On Tick（event.onTick） | 每帧 | 每帧触发，驱动持续行为 |
| On Click（event.onClick） | 点击时 | 指针射线命中目标实体时触发 |

### 逻辑容器类（logic）

大框卡片：拖入框内的节点以 containerId 归属该容器（可嵌套），运行时由容器决定子节点的执行时机。

| 类型 | 端口 | 说明 |
| --- | --- | --- |
| 状态机容器（fsm.container） | in: 进入(exec) / 事件(exec) / 条件(boolean) / 作用域(实体集)；out: 退出(exec) / 输出(实体集)；参数: 状态列表、初始状态、迁移守卫、重复进入 | 把携带 .fsm 的原型卡连到「作用域」自动读取状态（也可在检查器手填状态列表/初始状态）；「进入」激活初始状态，「事件」口按事件名切换状态，「条件」口接入比较结果（上升沿：比较卡「触发事件名」即目标状态）；进入状态时执行归属该状态的子节点链；**迁移守卫** `from>to` 逗号列表限制指定迁移只允许从某状态出发（只列要限制的，留空不限制）；重复切到当前状态默认忽略（勾选「重复进入」可重入）；支持嵌套 |
| 行为树容器（bt.container） | in: 进入(exec) / 条件(boolean) / 作用域(实体集)；out: 退出(exec) / 输出(实体集)；参数: 模式、重跑间隔 | 把携带 .bt 的原型卡连到「作用域」读取树构成（模式取树根类型，卡片角标展示）；成员卡不参与全局事件驱动，由容器调度——**顺序**（sequence，默认）：进入时按纵向顺序全部执行；**选择**（selector）：条件口布尔源与成员按纵向顺序一一配对，只执行第一个为真条件所配对的成员；**并行**（parallel）：进入时全部执行，激活期间每帧重跑成员链（放轻量卡片）。「重跑间隔」> 0 按秒周期性重跑；进入过一次即激活，激活期间框内帧驱动器（巡逻/追击/旋转等）每帧步进；支持嵌套 |

- 子节点的状态归属：容器内节点选中后，在检查器顶部选择「所属状态」（仅状态机容器）；未设状态归属 = 任意状态都执行；
- 容器内节点不参与全局事件驱动，只由容器调度（状态机按当前状态、行为树按模式：进入时 / selector 配对 / parallel 每帧）；
- 容器内的帧驱动器（巡逻/追击/旋转等）仅在所属状态激活时步进；
- 容器外的帧驱动器不随状态切换停止：把「中断开关」（flow.gate）串在其执行链上，用状态子节点链触发开关的「关/开」口，即可随状态中断/恢复（如进入追击状态中断巡逻/导航，回到巡逻状态闭合）；
- 追击期间想让巡更的 Nav Agent 一并停下：把代理实体接入「追击目标」的「目标」口（多输入）——追击联动会暂停代理巡回、脱离追击自动重寻路；代理随追击被带到终点附近，回到巡逻状态无瞬移；
- 巡逻的路径点与追击的目标按世界坐标解算：路径点/目标实体应**独立于移动者**（不能是移动者自身或其子级——它们随移动者一起动、永远到不了），跨父级（如子级挂在父实体下）不受影响。

### 驱动器类（driver）

每帧持续语义（无执行链时按帧触发独立运行；接入执行链则随链启动后持续步进）。

| 类型 | 参数 | 说明 |
| --- | --- | --- |
| 持续旋转（op.spin） | X/Y/Z 角速度（度/秒） | 每帧按角速度累计旋转 |
| 上下浮动（op.bob） | 幅度、周期（秒） | 每帧按正弦往复平移 Y（以启动位置为基准） |
| 路径巡逻（op.patrol） | 巡逻距离、速度、轴、朝向移动方向；「路径点」口可接入路径点实体集 | 有路径点：按**世界坐标**依次巡回（路径点挂在偏移父级下也正确）；无路径点：沿轴在起点与起点+距离间往返；移动时朝向移动方向（+Z 前向，同导航代理；可关，关闭后姿态由你自管） |
| 追击目标（op.chase） | 速度（units/s）、朝向移动方向；「追击目标」口接入实体 | 每帧朝目标移动并朝向移动方向（可关）；场景有导航区域时**自动按烘焙网格寻路绕行障碍**（每 0.4s 或目标位移超 1m 重寻路；不可达回退直线）；常与实体距离 + 分支组合成追击/放弃 |
| 导航移动（op.navMove） | 高度偏移；「导航代理」口接入 Nav Agent 原型卡 | 每帧贴合导航代理位姿（位置 + 朝向 + 高度偏移） |

### 操作类（op）

原子行为——分两组：**操作**（一次性/交互语义）与**驱动器**（每帧持续语义，右键菜单单列）。

| 类型 | 触发时机 | 参数 | 说明 |
| --- | --- | --- | --- |
| 设置属性（op.set） | 启动时 | 属性路径、值 | 把目标的指定属性设为 value（绝对值语义） |
| 获取子级（op.children） | — | — | 实体集变换卡（无执行引脚）：目标集 → 各目标的**直属子级实体集**（合并去重），输出可接任意操作「目标」、ForEach「集合」或属性读取「实体」引脚；只取场景层级的下一层，深层子级再串一张本卡；ForEach「当前」引脚可接操作「目标」，实现按序索引子级逐个操作 |
| FSM 事件（op.fireFsm） | 点击时 | 事件名 | 向目标的状态机发送事件（语义同 `engine.logic.fire`） |
| FSM 参数（op.setFsmParam） | 启动时 | 参数名、值 | 写目标状态机黑板参数（语义同 `engine.logic.setParam`） |

驱动器组（每帧持续语义；详细说明见「驱动器类」）：持续旋转（op.spin）、上下浮动（op.bob）、路径巡逻（op.patrol）、追击目标（op.chase）、导航移动（op.navMove）。

> 卡片去重原则：能由通用卡组合替代的一次性卡不再单列（如「点击显隐」= 属性读取 `visible` → 分支 → 设置属性 `visible` 0/1，已移除）。

通用属性路径（`op.set` 的写入与 `entity.prop` 的读取共用同一套寻址，读写对称；解析规则见 `runtime/graph-prop-path.ts`）：

```
position.x|y|z / scale.x|y|z     变换分量（局部）
rotation.x|y|z                    旋转分量（一律度制：写入 45 即 45°）
worldPosition.x|y|z               世界位置（仅读取）
position / rotation / scale       整段向量（读取输出 vec3）
visible / active / name / tag / kind / id   状态与身份
light.intensity / distance / angle(度) / penumbra / color(0xRRGGBB)
material.<标量属性>（如 opacity）与 material.color / material.r|g|b
userData.<键>                     节点 userData（仅已存在的标量键）
（子级实体不经路径寻址——读写子级属性先用「获取子级」把作用对象换成子级，
  配 ForEach「当前」按序索引单个子级再接本套路径）
script:<脚本路径>:<属性>          脚本组件 @property 实时值（如 script:src/spin.ts:speed）
```

- 检查器「属性」用 ui-kit 统一可编辑下拉（ComboBox），候选按上游连入的原型/匹配实体动态生成（变换分量、灯光/材质分量与脚本 @property），也可手输任意路径；
- 写入畸形/不可写路径不改变目标，预览控制台给出可定位告警（`设置属性「…」失败`）。

操作 out 实体集可透传串联——下游操作共用上游目标集。例外：「获取子级」（op.children）的 out 是其目标的子级集（解析器驱动），不是透传。

### 变量类（variable）

图变量（具名数据槽，全图共享）的读写节点。

| 类型 | 说明 | 端口 |
| --- | --- | --- |
| Get 变量（var.get） | 读取图变量当前值（纯数据节点，拉模型求值） | out: 值（any） |
| Set 变量（var.set） | 写入图变量（执行链节点：从 value 入引脚取值写入） | in: exec + 值；out: next + 值 |

图变量在右侧「变量」面板管理（添加/重命名/删除/改类型/改初始值），类型为 number / boolean / string。

### 控制流类（flow）

| 类型 | 说明 | 端口 |
| --- | --- | --- |
| 分支（flow.branch） | 条件为真走 true 分支，否则走 false 分支 | in: exec + 条件(boolean)；out: true + false(exec) |
| 比较（flow.compare） | 比较两个数值，输出布尔 | in: A + B(number)；out: 结果(boolean)；参数: 运算符(>`<`==`>=`<=`!=) |
| For 循环（flow.for） | 从 start 到 end 步进 step | in: exec + start + end + step；out: loop + index + completed |
| ForEach 循环（flow.forEach） | 遍历实体集 | in: exec + 集合(entities)；out: loop + 当前(entity) + completed |
| While 循环（flow.while） | 条件为真时循环（最多 10000 次防死循环） | in: exec + 条件(boolean)；out: loop + completed |
| 中断开关（flow.gate） | 「开」+「关」（exec）；参数: 初始断开 | 电路开关式通断控制：串入执行链，「关」口触发后中断下游——执行链不再级联、下游帧驱动器（导航移动/路径巡逻/追击等）暂停步进，「开」口触发恢复；都不触发时按「初始断开」放行。常与状态机组合：进入追击状态关断巡逻/导航链，回到巡逻状态闭合 |

遍历上下文说明：

- ForEach「当前」是**遍历期引脚**——只在循环体执行链（loop 下游）中有效，遍历结束后回归空值；
- 帧驱动器（路径巡逻/追击/导航移动等）每帧求值不在遍历上下文，因此「当前」不能直接接驱动器的参数口；要让驱动器遍历一组实体，直接接**实体集输出**（获取子级/匹配/原型）——例如路径巡逻的「路径点」接「获取子级」输出即按子级顺序巡回；
- 若要对每个子级各执行一次操作，用 `获取子级 → ForEach → loop → 操作`，操作「目标」接「当前」即可。

### 数学/工具类（math）

纯数据节点，拉模型求值。

| 分类 | 类型 | 说明 |
| --- | --- | --- |
| 算术 | 加法/减法/乘法/除法/取余 | a ± × ÷ mod b（除零回退 0） |
| 三角 | 正弦/余弦/正切 | 角度制输入：sin(a°)/cos(a°)/tan(a°) |
| 向量 | 合成向量/分解向量 | x,y,z → vec3 / vec3 → x,y,z |
| 字符串 | 字符串拼接/转字符串 | a + b → string / 任意值 → string |
| 插值/工具 | 线性插值/钳制/绝对值 | lerp(a,b,t) / clamp(value,min,max) / \|a\| |

### 自定义类（custom）

用户可扩展的节点类型，表达式求值驱动。在右侧「自定义」面板管理定义：

- **类型键**：须以 `custom.` 开头；
- **端口**：输入/输出端口（id + 标签 + 数据类型）；
- **字段**：可编辑的字面量参数（在检查器编辑）；
- **表达式**：每个输出端口的求值表达式（JS 表达式，可引用输入端口 id、字段 key、`Math`）。

运行时按表达式编译求值；定义随图会话自动持久化。

## 数据类型与连线兼容

端口数据类型决定连线兼容性与运行时求值语义：

| 数据类型 | 说明 |
| --- | --- |
| exec | 执行（执行链通道） |
| entity | 实体 |
| entities | 实体集 |
| number | 数值 |
| boolean | 布尔 |
| string | 字符串 |
| vec3 | 向量3 |
| any | 任意（通配） |

兼容规则：同类型可连 / `any` 通配 / `entity` ↔ `entities` 可互连（提升/降级）。

## 预览

切到「预览」视图：与编辑器同一导出链路的轻量版——

1. 场景先落盘（共享会话 `sceneApi.save`）；
2. 组装网页运行时 + 项目配置 + 用户脚本编译产物；
3. **场景图注入**：图会话文档写入 `script-graph.json` + config 标记 `scriptGraph`（player 检测到即装配行为解释器）；
4. 本地静态服务 + iframe 运行。

预览栏：刷新（重新导出并刷新 iframe）/ 重新导出 / 浏览器打开。无设备仿真（编辑器内已有完整版）。

## 运行时执行模型

预览/发布产物中的 `graph-behaviors` 解释器解释场景图文档，把图上对原型定义的操作作为运行时行为执行（不修改场景数据，只在运行期改变实体表现）。

### 执行链级联（推模型）

- 事件节点（OnBegin/OnTick/OnClick）是执行链入口，有 next（exec 出端口）；
- 事件触发时沿 next → exec 级联执行下游操作链；
- 操作节点有 exec（exec 入端口）+ next（exec 出端口）；
- `var.set` 在 exec 链中执行：从 value 入引脚拉取数据 → 写入图变量 → 级联 next；
- 控制流节点（分支/循环）按条件选择 exec 出端口级联。

### 数据流求值（拉模型）

- 标量值（number/boolean/string/vec3）经数据引脚流动，exec 链节点按需拉取；
- `var.get` 是纯数据节点：输出引脚被拉取时读图变量当前值；
- 数学/比较/自定义节点按类型求值；
- 环防护：求值过程检测循环引用。

### 目标解析（实体集通道）

- 原型：按场景节点 id 精确匹配；
- 匹配：按标签/类型批量匹配；
- 操作 out 实体集透传 → 上游递归。

### 向后兼容

无 exec 入边的旧操作按 trigger 字段独立执行（无事件节点驱动的旧图仍可运行）。

### 与静态批处理的关系

静态批处理（InstancedMesh / 几何合并）会把原网格置 `visible=false` 并渲染烘焙副本，而图在运行期移动的是树中的原对象——因此 **图引用到的实体（原型 + 匹配命中）会被自动排除出批处理**（`graphReferencedEntityIds` → `optimizeScene.excludeNodeIds`），保证位姿变化始终可见；其余静态网格的优化不受影响。

排除会**沿父链向子树传播**：被图驱动的父节点（分组等）下的子网格同样不烘焙——它们运行期会跟随父级移动，烘焙副本只会停留在烘焙瞬间的世界位姿。同一规则也覆盖其它「父链可动」来源：祖先带脚本/刚体组件、动画剪辑绑定、导航代理节点。

## 模块架构与注入扩展

节点类型系统与运行时语义都走「模块注册表」，内置类型与扩展模块同一条通道：

- **类型目录（编辑器认知）**：`registerModule(manifest)` 注册一组节点类型（端口/字段/触发时机/能力位）；
  内置类型按 core-entity / core-event / core-op / core-driver / core-variable / core-flow / core-math /
  core-container 八个模块注册，自定义节点归并为 custom 模块——同 id 重注册 = 整体替换，
  类型键冲突整模块拒绝（不破坏已注册语义）；
- **能力位（capability）**：容器 / 实体集源 / 事件入口 / 原子操作 / 驱动器 / 表达式六项能力取代
  一切类型名特判——声明能力的类型自动获得画布渲染、菜单分组与运行时对应待遇；
- **运行时语义（handler 模块）**：`createGraphBehaviors(ctx, modules)` 接受注入的
  `GraphRuntimeModule`（ops/drivers/data/executors/resolvers/containers 六张按类型键的语义表），
  与内置 core 模块共用同一张 kernel 分发表；player 按 `config.scriptGraphModules`
  动态装载模块 URL 列表（L1 扩展通道，与脚本同一信任边界）；
- **模块未装载（unresolved）**：文档中显式类型查无注册表时节点保留并标记 `unresolved`——
  编辑器灰卡显示「模块未装载」（字段留存，模块装载后恢复），运行时跳过并告警，绝不静默丢内容；
- **文档指纹**：`.graph` 文档含 `formatVersion` 与 `modules`（节点引用过的模块 id+version），
  装载方可据此校验模块可用性。

## 持久化

- 场景图随场景自动持久化到 `graph/` 目录（与 `assets/`、`src/` 同级）；
- 文件后缀 `.graph`（如 `graph/Main.graph`），与场景文件同名；
- 防抖自动保存（约 600ms），用户不感知文件（sidecar 旁路）；
- 自动保存写入 `formatVersion`（当前 2）与节点引用的 `modules` 模块指纹；
- 预览导出时随产物注入（`script-graph.json`）由运行时解释执行；
- 卸载前冲刷未落盘的图会话。

### 文件格式

`.graph` JSON 文档结构：

```jsonc
{
  "nodes": [
    {
      "id": "n1",              // 图内唯一 id
      "type": "entity.proto",  // 节点类型键
      "x": 100, "y": 200,      // 画布坐标
      "entityId": "…",         // 原型：场景实体 id
      // 匹配节点：matchMode + matchPattern
      // 操作节点：opType + params
      // 变量节点：varId
      "title": "…"             // 显示名覆盖（可选）
    }
  ],
  "edges": [
    { "id": "e1", "srcNode": "n1", "srcPort": "out", "dstNode": "n2", "dstPort": "in" }
  ],
  "comments": [
    { "id": "c1", "x": 50, "y": 50, "w": 240, "h": 140, "text": "…", "color": "#dcdcaa" }
  ],
  "variables": [
    { "id": "v1", "name": "speed", "dataType": "number", "value": 10 }
  ],
  "customNodes": [
    {
      "id": "cd1", "type": "custom.node1", "label": "自定义节点 1",
      "desc": "", "color": "#4ec9b0",
      "inputs": [{ "id": "a", "label": "A", "dataType": "number" }],
      "outputs": [{ "id": "result", "label": "结果", "dataType": "number" }],
      "fields": [],
      "expressions": { "result": "a" }
    }
  ]
}
```

加载时对全部字段做收敛解析（非法值回默认/剔除），旧格式 `kind`/`opType` 自动迁移为 `type`，旧场景图可无损打开。
