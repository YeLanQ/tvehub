# 项目管理

首页窗口提供项目、模板、偏好设置、创意工坊与开发者服务五个分区。

## 项目

- **新建项目**：选择位置与名称，可套用工程模板；创建 `project.config.json`、`assets/`、`src/` 等标准结构并打开；
- **打开**：浏览文件夹打开已有项目；最近项目以卡片列表展示（名称、场景数、路径）；
- 项目卡片「⋯」菜单：打开项目 / 在文件夹中显示 / 重命名项目 / 移动到垃圾篓（系统回收站，可恢复）/ 从列表移除（仅清除最近记录，不动磁盘文件）。

## 项目目录结构

打开项目后的标准结构（新建时自动生成）：

```
<项目根>/
├─ project.config.json   项目设置（版本、主场景、显示、物理、标签与层）
├─ build.config.json     构建配置（构建面板保存后生成）
├─ assets/               场景、模型、纹理、音频、材质、着色器、动画、预制体
├─ src/                  TS 脚本（只能放脚本）
├─ internal/             内置只读资产（材质/着色器/模板，只可引用不可修改）
└─ build/web/            构建产物（构建后生成）
```

## 模板

工程模板是新建项目时可选的页面骨架，内置模板直接可用，列表在此查看。新建项目对话框按模板类别（左栏）→ 模板卡片（中栏，标注内置/自定义）→ 模板信息与表单（右栏）三步选择；用户自定义模板放在 exe 旁 `public/templates`（同名内置优先）。

## 偏好设置

三个类别页签：

- **主题**：编辑器主题色与外观（当前为深色主题）；
- **项目**：**默认项目位置**——新建项目时的默认父目录，持久化到应用配置目录；
- **关于**：版本信息。

## 创意工坊

资源仓库浏览器：内容来自 `public/repos` 下的分类目录（**一个子目录一个分类，标签名取目录名并首字母大写**，新增 `public/repos/<目录>` 即自动出现同名标签），页面为**左标签栏 + 右内容栏**两栏布局——左栏切换分类（带文件数徽标），右栏展示该分类的文件卡片（名称、描述、大小、内容预览）。

| 分类 | 内容 | 可在工坊增删改 |
| --- | --- | --- |
| `code` | 脚本原型（`.ts`，一个原型一个独立文件） | 是（新原型落盘为 `<名称>.ts`） |
| `effect` | 效果原型（`.shader` 效果着色器） | 是（新原型落盘为 `<名称>.shader`） |
| 其它 | 新增 `public/repos/<目录>` 即自动出现同名标签 | 否（只读浏览，直接维护目录内容） |

- 增删改：右栏「添加原型」/「编辑」/「删除」，描述写在首部注释 `// @desc: 描述`（可选，卡片直接显示）；改名 = 另存新文件 + 删旧文件；
- 文本文件（`.ts`/`.shader`/`.json`/`.md` 等）预览内容，二进制文件只列信息；
- 「打开目录」在系统文件管理器中打开当前分类目录，放入文件后点「刷新」即可显示；
- `effect` 内置 6 个效果着色器示例（边缘光 / 扫描线 / 全息投影 / 溶解消失 / UV 流光 / 顶点波动）：
  可直接编辑，也可复制到项目的 `assets/shaders/`（Shader 指令名会随导入自动跟随路径）后
  在材质卡片挂载（见[着色器与自定义效果](shaders.md)）；
- `code` 的脚本原型含 `{{CLASS_NAME}}` 占位符（创建脚本时替换为脚本类名）；
  使用方式：资产面板右键「**创意工坊 ▸ 标签 ▸ 内容**」选择一项即按该内容新建项目资产——
  **任意可编辑目录都可调起**（不局限 `src/`）：
  - `Code` 标签（脚本原型）→ 新建脚本，固定创建在项目 `src/` 下并自动打开（提示中显示真实目标路径）；
  - `Effect` 标签（效果原型）→ 把原型源码写成本目录下的 `.shader` 资产（指令名自动跟随路径，
    随后在材质卡片挂载；`src/` 下不显示该标签）。

仓库目录随应用分发（开发为仓库 `public/repos`，安装后为 exe 同级 `public/repos`），
用户新增的文件写在该目录，不随应用更新覆盖。

## 项目设置

工具栏点击项目信息（⚙）打开，配置写入项目根 `project.config.json`，分四页：

### 基础信息

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 版本 | 项目版本号 | `0.0.1` |
| 描述 | 项目描述（可选） | 空 |
| 主场景 | 项目内 `.scene` 资产路径（预览/构建的入口场景） | 未设置 |
| 入口脚本 | `src/**.ts` 中可选一个，随预览/发布运行（挂载在场景根节点）；留空则仅脚本组件运行 | 无 |

### 显示与运行

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 设计分辨率 | 宽 × 高（1..16384）+ 常用分辨率预设；修改即时同步到相机辅助视锥线框 | 1280 × 720 |
| 屏幕方向 | 自动（跟随设备）/ 竖屏 / 横屏 | 横屏 |
| 缩放模式 | 不缩放 / 固定宽度 / 固定高度 / 固定宽高比 / 等比铺满 | 固定宽高比 |
| 渲染合成 | HDR 合成（ACES 色调映射）/ LDR 合成 | LDR |
| 抗锯齿 | 无 / MSAA 2x / 4x / 8x | MSAA 2x |
| 渲染后端 | WebGL（稳定）/ WebGPU（实验，不可用时自动回退 WebGL2）/ 自动（优先 WebGPU）；启动/重载视口时生效 | WebGL |

常用分辨率预设：竖屏 640×960、720×1280、768×1024、1080×1920；横屏 1280×720、1334×750、1920×1080、2560×1440、3840×2160。

渲染后端差异（切换后端后需重载视口）：

- 内置材质（physical / toon / unlit）两种后端下表现一致（three 自动转换到节点材质）；
- **粒子系统**在 WebGPU 下改用 TSL 节点材质渲染（几何与参数语义不变，外观一致）；
- **着色器 Hook（.shader 的 Hook 块）在两种后端都生效**：WebGL 走 onBeforeCompile 注入 GLSL，WebGPU 翻译为 TSL 接节点材质端口；仅 Fragment 端口与受控子集外的写法在 WebGPU 下不生效（编辑器控制台给出原因）。

### 物理

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 启用物理模拟 | 启用后预览/发布产物对挂「刚体」组件的节点自动开始模拟；编辑器视口的模拟经检查器 Physics 卡片 ▶/⏹ 控制 | 关 |
| 物理引擎 | Rapier（默认）/ Jolt / Ammo.js (Bullet)；预览/发布产物按所选引擎按需加载（未启用物理的产物不打包引擎） | Rapier |
| 重力 | 世界加速度（米/秒²），影响全部动力学体；地球重力约为 Y = -9.81 | (0, -9.81, 0) |

物理配置保存后即时生效（编辑器内按最新引擎/重力/开关运行）。物理模拟按固定步长 1/60s 步进。

### 标签与层

| 项 | 说明 |
| --- | --- |
| 标签（Tags） | 项目级命名标签列表（内置 `Untagged` 不可删）；节点在检查器 Node 卡下拉选择，用户脚本经 `entity.tag` / `findByTag` 按标签筛选实体。节点上已存储但不在列表中的标签会原样保留。保存时自动 trim / 去重 / 去空 |
| 层（Layers） | 渲染层级，最多 32 个（three.js 上限），内置层 0 `Default` 不可删不可改名。「添加层」占用最低空闲索引（默认名 `Layer N`）；删除层 = 清空名字，引用了它的节点回退显示 `Layer N`。节点在检查器 Node 卡单选所属层；相机与灯光用 Culling Mask 只渲染/照亮所选层 |

层与 Culling Mask 的渲染语义见「场景编辑 › 渲染层级与标签」。

## 开发者服务（桌面端）

首页「开发者服务」分区提供**本地控制服务器**（TCP + MCP 端点）：编辑器窗口执行命令（场景读写、节点增删改、资产操作、预览截图等），可配置端口与工具权限、复制 MCP 配置接入外部 AI/工具链。

- **控制服务器**：启用后监听本地 TCP 端口（默认 **39100**，0 = 随机端口，占用自动换随机；重启生效），协议为**换行分隔 JSON**（如 `{"id":1,"method":"editor.state","params":{}}`）；同一端口同时提供 **MCP streamable-http 端点 `/mcp`**；应用启动自动开启（浏览器直开环境不可用）；
- **工具权限**：约 19 个工具开关分 8 组（编辑器状态/项目、场景、节点增删改、状态快照、预览控制、屏幕截图、资源管理），缺省全开、逐个可关；关闭对 TCP 与 MCP 同时生效，持久化在浏览器本地存储；
- **MCP 服务**：服务名 `tve-devtools`；页面展示 HTTP 端点（点击复制）、已启用工具清单，以及可直接粘贴进 MCP 客户端配置的 streamable-http / stdio 两种配置 JSON（stdio 模式由客户端拉起 `mcp.exe` 子进程，`--port` 转发到控制服务器）。

命令分组：编辑器（状态/最近项目/打开关闭项目）、场景（读写/树）、节点（选中/添加/删除/设置）、状态快照、预览（打开/关闭/启停/截图）、资源（列表/新建/删除/重命名）等；每个工具的启用状态即上面「工具权限」。
