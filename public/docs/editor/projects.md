# 项目管理

首页窗口提供项目、模板、偏好设置、创意工坊与开发者服务五个分区。

## 项目

- **新建项目**：选择位置与名称，可套用工程模板；创建 `project.config.json`、`assets/`、`src/` 等标准结构并打开；
- **打开**：浏览文件夹打开已有项目；最近项目以卡片列表展示（名称、场景数、路径）；
- 项目卡片「⋯」菜单：打开项目 / 在文件夹中显示 / 重命名项目 / 移动到垃圾篓（系统回收站，可恢复）/ 从列表移除。

## 模板

工程模板是新建项目时可选的页面骨架，内置模板直接可用，列表在此查看。

## 偏好设置

- **主题**：编辑器主题色与外观；
- **默认项目位置**：新建项目时的默认父目录。

## 创意工坊

资源仓库浏览器：内容来自 `public/repos` 下的分类目录（**一个子目录一个分类，标签名取目录名并首字母大写**，新增 `public/repos/<目录>` 即自动出现同名标签），页面为**左标签栏 + 右内容栏**两栏布局——左栏切换分类（带文件数徽标，高度固定、分类多时栏内滚动），右栏展示该分类的文件卡片（名称、描述、大小、内容预览）。

| 分类 | 内容 | 可在工坊增删改 |
| --- | --- | --- |
| `code` | 脚本原型（`.ts`，一个原型一个独立文件） | 是（新原型落盘为 `<名称>.ts`） |
| `effect` | 效果原型（`.shader` 自定义着色器） | 是（新原型落盘为 `<名称>.shader`） |
| 其它 | 新增 `public/repos/<目录>` 即自动出现同名标签 | 否（只读浏览，直接维护目录内容） |

- 增删改：右栏「添加原型」/「编辑」/「删除」，描述写在首部注释 `// @desc: 描述`（可选，卡片直接显示）；
  表单顶部的 `分类/名称.扩展名` 即落盘路径预览；
- 文本文件（`.ts`/`.shader`/`.json`/`.md` 等）预览内容，二进制文件只列信息；
- 「打开目录」在系统文件管理器中打开当前分类目录，放入文件后点「刷新」即可显示；
- `effect` 内置 3 个自定义着色器示例（全息投影 / 溶解消失 / UV 流光）：可直接编辑，也可复制到项目的
  `assets/shaders/`（Shader 指令名会随导入自动跟随路径）后在材质卡片「着色器」下拉里挂载；
- `code` 的脚本原型含 `{{CLASS_NAME}}` 占位符（创建脚本时替换为脚本类名）；
  使用方式：资产面板右键「**创意工坊 ▸ 标签 ▸ 内容**」选择一项即按该内容新建项目资产——
  **任意可编辑目录都可调起**（不局限 `src/`）：
  - `Code` 标签（脚本原型）→ 新建脚本，固定创建在项目 `src/` 下并自动打开（提示中显示真实目标路径）；
  - `Effect` 标签（效果原型）→ 把原型源码写成本目录下的 `.shader` 资产（指令名自动跟随路径，
    随后在材质卡片「着色器」下拉里挂载；`src/` 下不显示该标签）。

仓库目录随应用分发（开发为仓库 `public/repos`，安装后为 exe 同级 `public/repos`），
用户新增的文件写在该目录，不随应用更新覆盖。

## 项目设置

工具栏点击项目信息（⚙）打开，配置写入项目根 `project.config.json`，分四页：

### 基础信息

| 项 | 说明 |
| --- | --- |
| 版本 | 项目版本号 |
| 描述 | 项目描述（可选） |
| 主场景 | 项目内 `.scene` 资产路径 |
| 入口脚本 | `src/**.ts` 中可选一个，随预览/发布运行（挂载在场景根节点）；留空则仅脚本组件运行 |

### 显示与运行

| 项 | 说明 |
| --- | --- |
| 设计分辨率 | 宽 × 高 + 常用分辨率预设；修改即时同步到相机辅助视锥线框 |
| 屏幕方向 | 自动（跟随设备）/ 竖屏 / 横屏 |
| 缩放模式 | 不缩放 / 固定宽度 / 固定高度 / 固定宽高比 / 全屏拉伸 |
| 渲染合成 | HDR 合成 / LDR 合成 |
| 抗锯齿 | 无 / MSAA 2x / 4x / 8x |
| 渲染后端 | WebGL（稳定）/ WebGPU（实验，不可用时自动回退 WebGL2）/ 自动（优先 WebGPU）；启动/重载视口时生效 |

### 物理

| 项 | 说明 |
| --- | --- |
| 启用物理模拟 | 启用后预览/发布产物对挂「刚体」组件的节点自动开始模拟；编辑器视口的模拟经检查器 Physics 卡片 ▶/⏹ 控制 |
| 物理引擎 | Rapier / Jolt / Ammo.js (Bullet)；预览/发布产物按所选引擎按需加载（未启用物理的产物不打包引擎） |
| 重力 | 世界加速度（米/秒²），影响全部动力学体；地球重力约为 Y = -9.81 |

物理配置保存后即时生效（编辑器内按最新引擎/重力/开关运行）。

### 标签与层

| 项 | 说明 |
| --- | --- |
| 标签（Tags） | 项目级命名标签列表（内置 `Untagged` 不可删）；节点在检查器 Node 卡下拉选择，用户脚本经 `entity.tag` / `findByTag` 按标签筛选实体。节点上已存储但不在列表中的标签会原样保留 |
| 层（Layers） | 渲染层级，最多 32 个（three.js 上限），内置层 0 `Default` 不可删。节点在检查器 Node 卡单选所属层（Unity Layer 语义）；相机与灯光用 Culling Mask 只渲染/照亮所选层 |

层与 Culling Mask 的渲染语义见「场景编辑 › 渲染层级与标签」。
