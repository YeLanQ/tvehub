# UI 系统（Canvas-Widget）

编辑器内置 2D UI 系统：**画布（UI Canvas）** 是容器根，**Widget**（文本/图片/按钮/布局容器）挂其下参与叠加。UI 屏幕叠加渲染，恒显示在 3D 场景之上（预览/构建产物为「场景 + UI 叠加」）。

## 坐标与单位

- **UI 空间**：画布原点对齐屏幕中心，+x 向右、+y 向上；纵向可见范围恒为 10 个 UI 单位（透视相机按 fov 自动推距离、正交相机按缩放对齐——编辑器与运行时同一套数学，与相机 fov 无关的恒定标尺）；
- **2D 设计标准**：100 设计像素 = 1 UI 单位。画布渲染尺寸 = 设计分辨率 / 100（如 1280×720 → 12.8×7.2 单位）；Widget 的位置/尺寸/边距序列化均为 UI 单位，检查器按**像素**显示并自动换算；
- Widget 的 3D 变换中只有**旋转 Z** 与 **2D 缩放**可编辑；位置由锚点系统每帧解析接管（见下文），直接改 position 不生效。

## 视图模式：场景 与 布局

- **场景视图**：画布整体隐藏（渲染与点选同规则），专注 3D 场景编辑；
- **布局视图**（顶部工具栏「布局」，选中画布节点时自动切换）：UI 独占渲染——场景内容临时隐藏，只显示画布子树与编辑辅助（gizmo）；
- **布局视图 2D 导航**：滚轮缩放（以指针为锚点）、右键/中键拖拽平移；切回场景视图自动复位；
- 布局视图恒按画布**设计尺寸 1:1** 显示；缩放模式是运行时屏幕适配方案，编辑器不参与映射。

## 创建 UI 节点

层级面板右键「添加节点」> **UI** 分组：

| 类型 | 说明 |
| --- | --- |
| UI Canvas | 画布容器根（Widget 建议挂其下） |
| Text | 多行文本 |
| Image | 图片 / 纯色矩形 |
| Button | 可点击按钮（背景 + 标签） |
| Layout | 布局容器（横排/竖排/网格排列子元素） |

新建画布的设计尺寸默认取**项目设置 › 显示与运行 › 设计分辨率**（按屏幕方向自动定向）。

## 画布（UI Canvas）卡片

- **渲染模式**：屏幕叠加（Overlay，当前唯一模式）；
- **设计宽度 / 设计高度**：画布设计分辨率（设计像素，1..16384；100px = 1 UI 单位）；
- **Sort Order**：画布整体排序（-500..500）。多画布叠加时先按此比较（大者在上），再比画布内 Widget 的 Sort Order；
- **缩放模式**：由项目设置统一控制（所有画布共用），不在画布上单独配置。

## 屏幕适配（缩放模式）

项目设置 › 显示与运行 › 缩放模式，决定画布设计矩形映射到屏幕的策略（**仅预览/构建产物运行时生效**；等比模式下 sx=sy，Widget 等比缩放、不被非等比拉伸）：

| 模式 | 行为 |
| --- | --- |
| 不缩放（noscale） | 画布按设计尺寸原样显示，不随屏幕缩放 |
| 固定宽度（fixedwidth） | 宽度铺满屏幕的等比缩放（高度随屏幕比例变化） |
| 固定高度（fixedheight） | 高度铺满屏幕的等比缩放（宽度随屏幕比例变化） |
| 固定宽高比（fixedauto） | 等比铺满（cover）：取较大缩放比铺满屏幕，超出部分裁切 |
| 等比铺满（full） | 等比包含（contain）：取较小缩放比完整显示不裁切，可能有留白 |

## Widget 公有：2D 变换与锚点

图片/文本/按钮/布局容器共有锚点定位字段（Unity uGUI 同语义）：

- **锚点 anchorMin / anchorMax**：父矩形上的归一化锚点（0..1）。某轴 min == max 为**点锚点**；min < max 为**拉伸锚点**；
- **点锚点轴**：位置 = `anchoredPosition`（枢轴相对锚点的偏移，像素），尺寸 = 设计尺寸 W/H；
- **拉伸轴**：矩形 = 父矩形上两锚线之间收进 `offsetMin`（左/下）与 `offsetMax`（右/上）边距——尺寸随父矩形推导，屏幕适配时自动跟随拉伸，不会错位；
- **枢轴 pivot**：Widget 自身归一化基准点（0..1），点锚点定位与旋转都绕它；
- **锚点预设**：锚点卡提供九宫格（居中/四角/四边）与横向/纵向/双向拉伸一键预设（切换时保留视觉偏移）；
- **Sort Order**：画布内叠加序（-999..999），大者在上；同 SortOrder 按层级顺序稳定细分（越靠后越在上）；
- **gizmo 拖拽**：布局视口中拖动/缩放 Widget 自动换算回 anchoredPosition 或 offset 边距（拉伸轴拖位置不可表达时改写边距）。

## 文本（Text）

- **内容**：多行文本（`\n` 分行，超界自动换行，逐字符断行对中文友好）；
- **样式**：字号（设计像素）、颜色、粗体、斜体；
- **字族**：System 系统无衬线 / Serif 衬线 / Mono 等宽；
- **对齐**：相对文本框的左/中/右水平对齐（垂直居中）。

## 图片（Image）

- **图片**：项目图片资产（png/jpg/webp 等），留空 = 纯色矩形；构建导出自动打包引用的贴图；
- **颜色**：着色与图片相乘（白图 × 颜色 = 染色；无图片时即矩形底色）。

## 按钮（Button）

- **背景**：图片资产（空 = 纯色）+ 着色；
- **标签**：文本内容 / 颜色 / 字号 / 粗体，居中于按钮矩形；
- **Interactable**：可交互开关。关闭后仅展示，不参与点击命中；
- **点击命中**：运行时在画布空间做指针反投影 + 矩形命中测试，按渲染序取最上层可交互按钮；脚本经 `engine.ui.onClick(entity, cb)` 订阅（见 [SDK UI](../sdk/ui.md)）。

## 布局容器（Layout）

按设置排列**直接子 UI 节点**（Layout Group 语义）：

- **排列模式**：None 不排列（纯容器）/ Horizontal 横向一行 / Vertical 竖向一列 / Grid 网格；
- **Padding**：内容区内边距（内容区 = 容器矩形收进四边）；**Spacing**：子元素间距（横向/纵向）；
- **Grid Columns**：网格列数（行数由子元素数量推导，格子尺寸 = 子元素最大宽高）；
- 子元素位置由容器接管（子元素自己的 anchoredPosition 被忽略），在槽位/格子内**居中**；排列顺序 = 层级子节点顺序；
- 容器自身是「无形 Widget」：有尺寸/锚点/SortOrder（可被父布局排列）但不渲染内容（编辑器画布内显示辅助框，选中可点选）；布局容器可嵌套。

## 渲染排序

渲染序由三级合成（材质统一关深度测试，按序叠加）：

1. 画布 Sort Order（多画布之间，大者在上）；
2. Widget Sort Order（画布内，大者在上）；
3. 层级树序（同 SortOrder 时，画布下越靠后的节点越在上层）。

## 脚本控制

预览/构建运行时可用脚本读写 UI 并订阅按钮点击：节点类（`UICanvasNode` / `UIImageNode` / `UITextNode` / `UIButtonNode` / `UILayoutNode`）与 `engine.ui` API 见 [SDK UI 文档](../sdk/ui.md)。运行态属性写入即时生效，不回写场景文件。
