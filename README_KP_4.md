# TvE Hub

可视化3D编辑器。覆盖完整创作闭环，编辑器与导出产物运行同一套网页运行时，语义零漂移。

> 本分支为 **kp-4**，当前版本 **v0.1.4**。上一代基线说明见 [README_KP_3.md](README_KP_3.md)（kp-3）与 [README_KP_2.md](README_KP_2.md)（kp-2）。

桌面端为**多会话窗口架构**：首页窗口（TvE Hub）负责项目管理、模板、创意工坊、白板与共享，每个项目一个独立编辑器窗口（TvE Editor）；窗口与会话生命周期由后端统一管理，浏览器环境回退单窗口视图切换。脚本 SDK 的命名空间为 `tve`。

## 产品哲学

> **人的有限时间不能耗费在无限的工具学习中。**

v0.1.4 的智能助手延续这一哲学：你说想要什么，助手替你跑完全程——它的思考、计划与每一步执行都看得见，写坏文件、空口宣称完成这类事被从机制上拦住。

## v0.1.4 更新内容

### 智能助手：看得见思考与计划的随行搭档

- **思考可见**：模型思考过程实时上屏（单行滚动跟随最新）；供应商可按模型配置思考开关与强度（低/中/高/最高，四档透传适配不同模型档位）；
- **任务真实落地**：没执行过任何工具就宣称「任务完成」的空话会被识别并拉回真执行；一步一停自动续跑、重复调用/复读/坏格式自动救援，弱模型的常见空转大幅收敛；
- **大脑语义单元化**：自然语言先归一化（类型/锚点/文件校验）再检索知识图谱——官方文档与工坊原型已入图且外部更新免重编；多步任务拆成计划逐单元推进，原子命令大脑直执行、模糊单元助手细化；

### 助手文件操作：格式锁定与关联保护

- **专用写入通道**：场景（scene.write）与着色器（shader.write）写入前按引擎同款规则校验，写坏即拒并回喂具体原因，不再产生引擎打不开的文件；.meta/.fsm/.bt/.mat/.terrain 等引擎管理格式与项目根配置拒绝直写；
- **挂脚本走组件**：脚本作为组件挂到节点属性面板（与手动添加组件同源，支持内置组件、防重复挂载），不再误建脚本子节点；
- **大文件读法**：文件内模块索引 + 按模块读全文 + 按行分页（带翻页游标），改前读全、改后核对，杜绝拿半截文件当全文回写；
- **关联检查**：改名/移动/删除脚本、着色器、资产前先查引用方，改 @property 或着色器属性名不再悄悄丢失已调参数；

### 面板与工作区体验

- **上下文窗口可配**：按模型实际窗口填写（128K～1M），预算内工具结果与历史全量保留，大窗口模型不再被固定截断卡容量；
- **输入框 @ 实时补全**工作区文件（↑↓/Enter/Esc 键盘流）；
- **过程容器按任务保留**：大脑过程容器与执行过程容器一样留在会话里，多任务不再只剩最后一个；
- **工作区同步**：助手写文件后文件树自动刷新（可手动 ⟳）；删除项目后工作区与会话列表同步收敛；运行中切会话/设置面板任务不丢；
- **输出净化**：空输出、伪标签、思考标签、复读的工具回喂不再污染对话；

### 图窗口

- 上下浮动/持续旋转接入内置缓动曲线（浮动三角往返×曲线，旋转按周期脉冲）；
- 追击目标新增「最小距离」：贴近即截停，不再绕着目标打转；
- 导航新增「恢复续走」：代理暂停恢复后从当前位置续走剩余路径点；
- 状态机新增「切换事件」映射：容器「事件>状态」可视化接线，比较卡触发下拉只列有效事件。

### 修复

- 预览导航烘焙把带碰撞体的采样地形误当障碍，代理不再原地不动；
- 场景被直写后编辑器一键从磁盘重载（project.open/scene.open），未保存的修改保留不被覆盖；
- 会话存储迁独立目录 + 消息即时落盘，退出/崩溃的丢失窗口缩到单条在途写入；
- 供应商地址返回思考内容时不再混进正文。
