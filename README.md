# TvE Hub

可视化3D编辑器。覆盖「搭场景 → 做 UI → K 动画 → 写脚本 → 配逻辑 → 网页预览 → 构建导出」的完整创作闭环，编辑器与导出产物运行同一套网页运行时，语义零漂移。

桌面端为双窗口架构：**首页窗口（TvE Hub）**负责项目管理、模板、创意工坊，**编辑器窗口（TvE Editor）**提供工具栏、停靠面板与中央工作区；浏览器环境回退单窗口视图切换。脚本 SDK 的命名空间为 `tve`。

## 功能特性

### 编辑器

- **双窗口架构**：首页窗口（项目管理、工程模板、偏好设置、创意工坊、开发者服务）+ 编辑器窗口；浏览器环境回退单窗口视图切换；
- **项目管理**：新建项目可套用工程模板（类别 → 模板卡片 → 信息与表单三步选择），最近项目卡片支持打开、在文件夹中显示、重命名、移动到系统回收站（可恢复）、移除记录；
- **停靠面板系统**：层级 / 属性（检查器）/ 控制台 / 资产 / 动画 五种面板，支持拖拽停靠、浮动窗口、合并标签页、布局持久化；动画聚焦模式下锁定布局防止误动；
- **四种视图模式**：场景（3D 编辑视口）/ 布局（UI 画布）/ 预览（内嵌网页运行）/ 脚本（代码工作台）；预览与脚本模式暂停编辑器视口渲染以节省资源；
- **检查器与组件**：变换、网格、灯光、相机、物理（刚体/碰撞体）、音源、粒子、脚本组件等卡片式编辑；
- **撤销/保存**：命令式撤销栈，未保存标记，快捷键与工具切换（W/E/R）。

### 场景与渲染

- 场景层级、节点多选、拖拽排序、预制体实例化、节点类型图标；
- 粒子系统、阴影、雾效、天空、LOD、静态批处理，WebGL / WebGPU 双渲染后端（不可用时自动回退）；
- **UI 系统**：UI 画布 + Widget（文本/图片/按钮/布局容器）、锚点布局、缩放适配、内置布局配方，可与 3D 场景混合编排；
- **动画编辑器**：关键帧剪辑、曲线编辑、录制、`.anim` 剪辑资产、动画图、骨骼动画（混合/加法层、IK、形态键、骨骼调试）；
- **着色器**：`.shader` 效果着色器资产（Properties 参数 + Hook 钩子），在材质卡片挂载，创意工坊内置 6 个效果示例（边缘光 / 扫描线 / 全息投影 / 溶解消失 / UV 流光 / 顶点波动）。

单位约定：位置/缩放 = 米，旋转 = 度，UI = 100 设计像素，y 向上，前向 = -Z。

### 逻辑与脚本

- **脚本系统**：代码工作台编写 TypeScript（编译、绑定节点、编辑器内智能提示与错误定位），`tve` SDK 提供 `@property` 装饰器声明脚本属性（类型推断/节点引用/组件引用/自动挂载）、`@nodeType` 脚本节点、`engine` 入口（时间、输入（含多点触控）、场景查询、动画、音频、粒子、物理、UI、补间、日志）、`math` 向量/角度工具、`tween` 链式补间（序列/并行、31 种缓动）、`utils`（Delegate/Pool/DataCenter）；
- **逻辑系统**：`.fsm` 状态机 / `.bt` 行为树可视化编辑器（节点画布、连线、黑板参数、事件、自定义右键菜单、适配视图）+ 运行时引擎，层级节点挂 FSM Runner / BT Runner 运行器（资产绑定、自动启动、时间倍率），检查器提供 Live 状态视图（运行控制、事件、强制切换、黑板实时查看），资产保存热重建；脚本侧 `engine.logic` 派发事件、读写黑板、监听状态、注册动作处理器；
- 编辑器与播放器共用同一套求值器，预览/导出语义一致。

### 地形 / 导航 / 物理

- **地形笔刷**：高度雕刻（抬升/压低/压平/平滑）+ splatmap 权重绘制（`.terrainmat` 多层混合材质），绘制实时预览、增量重烤；
- **导航系统**：地形/任意网格烘焙可行走场 + SDF 寻路 + 导航代理（单点/顺序巡回/最近可达三种目标模式，目标移动自动重评估路径）；
- **物理**：刚体与碰撞体组件，模拟在独立线程运行，不阻塞编辑与渲染主循环。

### 资产与构建

- **资产系统**：资产面板（导入、重命名、复制路径、按类型筛选），类型覆盖场景、模型、材质（`.mat`）、地形材质（`.terrainmat`）、纹理、音频、着色器、动画、预制体、脚本、逻辑资产（`.fsm`/`.bt`）；模型导入支持 glTF（含 Draco 压缩）、内嵌材质自动提取为 `.mat`、按材质槽位覆盖；项目 `internal/` 提供内置只读资产；
- **创意工坊**：脚本原型（`.ts`）与效果原型（`.shader`）仓库，资产面板右键按原型直接新建项目资产；
- **网页预览**：一键导出独立网页真实运行（保存 + 编译 + 打包运行时），控制台与错误实时回传编辑器，支持系统浏览器打开调试；设备仿真内置常见手机/平板机型（横竖屏、自定义分辨率与 DPR、缩放适配），完整验证移动端表现；
- **构建导出（Web）**：多场景构建（指定主场景入口）、发布模式（资源重命名 + 引用重写 + JSON 压缩）、资产 gzip 归档、CDN 模式、多导出模板；产物为纯静态文件输出到 `<项目>/build/web/`，可直接部署任意静态服务器或对象存储 + CDN；逻辑资产随场景自动打包。

## 项目目录结构

新建项目自动生成标准结构：

```
<项目根>/
├─ project.config.json   项目设置（版本、主场景、显示、物理、标签与层）
├─ build.config.json     构建配置（构建面板保存后生成）
├─ assets/               场景、模型、纹理、音频、材质、着色器、动画、预制体
├─ src/                  TS 脚本（只能放脚本）
├─ internal/             内置只读资产（只可引用不可修改）
└─ build/web/            构建产物（构建后生成）
```

## 仓库结构

```
src/
  framework/     # 编辑器引擎（场景/动画/物理/逻辑/导航/地形/脚本……各子系统）
  runtime/       # 播放器网页运行时（预览与构建产物使用，编辑器共用）
  app/           # 首页与编辑器窗口应用壳
  components/    # 通用业务组件
  ui-kit/        # 编辑器 UI 组件库
  lib/           # 数据层门面（唯一允许直接调用桌面端 IPC 的位置）
public/docs/     # 内置文档：editor/（编辑器）+ sdk/（脚本 API）
src-tauri/       # 桌面端后端（项目/资产管理、预览构建、资产协议、监视器）
scripts/         # 构建/生成脚本与 smoke 冒烟测试
```

分层守卫：全仓仅 `src/lib/` 允许直接调用桌面端 IPC，构建前由 `scripts/check-layers.mjs` 检查。

## 快速开始

环境要求：Node.js 18+、pnpm、Rust 工具链（构建桌面端安装包需要）。

```bash
pnpm install

# 浏览器开发模式（单窗口回退）
pnpm dev

# 桌面端开发模式（双窗口）
pnpm tauri dev

# 前端构建（含运行时打包、生成文件、类型检查、分层检查）
pnpm build

# 桌面端安装包构建
pnpm build:portable
```

## 质量检查

项目以 smoke 冒烟脚本做回归测试（Node 直跑），覆盖网格、物理、组件、着色器、粒子、阴影、地形、状态机、逻辑引擎/运行时、导航、输入、补间、脚本钩子等子系统：

```bash
pnpm smoke:logic-engine    # 示例：逻辑引擎 81 项
pnpm smoke:logic-runtime   # 示例：逻辑运行时 31 项
pnpm smoke:input-runtime   # 示例：输入运行时 43 项
pnpm check:layers          # 分层守卫检查
```

全部脚本见 `package.json` 的 `scripts`。
