# TvE Hub

可视化3D编辑器。覆盖完整创作闭环，编辑器与导出产物运行同一套网页运行时，语义零漂移。

> 本分支为 **kp-3**，当前版本 **v0.1.3**。上一代基线说明见 [README_KP_2.md](README_KP_2.md)（kp-2）与 [README_KP_1.md](README_KP_1.md)（kp-1）。

桌面端为**多会话窗口架构**：首页窗口（TvE Hub）负责项目管理、模板、创意工坊、白板与共享，每个项目一个独立编辑器窗口（TvE Editor）；窗口与会话生命周期由后端统一管理，浏览器环境回退单窗口视图切换。脚本 SDK 的命名空间为 `tve`。

## 产品哲学

> **人的有限时间不能耗费在无限的工具学习中。**

v0.1.3 的白板与共享延续这一哲学：灵感来了随手开一块白板，做好的东西一键分享给身边的人。

## v0.1.3 更新内容

### 白板：让你的想法向资产一样被管理

- **白板窗口**：首页新增「白板」分区，新建/打开即进入独立白板窗口（绘制、图层、富文本），不绑定项目、关了可再开；
- **白板资产管理**：白板按时间轴管理，支持标签、归档、删除，尺寸预设与自动刷新；
- **幻灯片放映**：图层当页播放，浮动工具条、四种切换方式、三种驱动方式（点击/自动/循环）；放映期间图层裁到画板内，可见区域只有白板；
- **内容增强**：切页动画接入缓动曲线（与元素动画共用一份曲线表）；文本排版改造——语法富文本、字形与描边；形状支持图片填充

### 共享：局域网发布

- 编辑器工具栏新增 **共享**：把网页预览发布到局域网，统一配置 + 地址二维码；
- 白板窗口增设 **共享**: 白板可生成放映页分享, 让你的想法不限设备；

### 编辑器体验

- draco 压缩、添加物理组件在项目未开对应开关时气泡提醒，可直达项目设置；
- ui-kit 统一气泡通知，替换 alert 与散落提示；
- 创意工坊导入按源文件名直接落盘，不再弹命名窗；
- 真机触摸：画布禁用浏览器手势与页面缩放，触摸拖拽不再被打断；
- 第三方许可证统一管理，首页「关于」动态展示许可清单。

### 修复

- 阴影掠射条纹与边缘锯齿；
- 布局视口变换工具随视图缩放膨胀；装载蒙版进度条回滚；
- 白板浮动工具条图标被内边距压小；ComboBox 打开即展示全量候选；
- dev 启动/服务期三类故障（资产直出、compiler 预置、engine 产物按内容落盘）；
- 运行时资产被 SPA 兜底成 HTML 导致 Worker Blob 语法错误（预览/构建两处根因）；
- 共享页弹出黑色空窗。
