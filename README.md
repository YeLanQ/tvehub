# TvE Hub

可视化3D编辑器。覆盖「搭场景 → 做 UI → K 动画 → 写脚本 → 配逻辑 → 网页预览 → 构建导出」的完整创作闭环，编辑器与导出产物运行同一套网页运行时，语义零漂移。

> 本分支为 **kp-2**。上一代基线（kp-1）的说明见 [README_KP_1.md](README_KP_1.md）；本文件在其基础上叠加 kp-2 的更新内容。

桌面端为**多会话窗口架构**：首页窗口（TvE Hub）负责项目管理、模板、创意工坊，每个项目一个独立编辑器窗口（TvE Editor），场景图窗口按需动态开启；窗口与会话生命周期由后端统一管理，浏览器环境回退单窗口视图切换。脚本 SDK 的命名空间为 `tve`。

## kp-2 重大更新：场景图

**我们在场景的基础上延伸出「场景图」的概念：将每一个场景视作一张图，场景中的每一个对象视为原型。** 由此设计了独立的场景图编辑窗口——不用动一行代码，通过驱动器和逻辑卡（执行链 + 数据流）即可扩展场景原型的行为，与脚本、逻辑资产共同构成三层创作通道。

- **独立编辑窗口**：从首页「打开场景图」或编辑器内进入，与编辑器同级的第三类窗口；与场景会话共享同一份数据（层级树实时同步、未保存修改跨窗口一致），同款工具栏/停靠系统/资产面板；图随场景侧车自动保存（`graph/<场景名>.graph`）；
- **原型与实体集**：层级拖入实体生成「原型」卡，「匹配」卡按标签/类型批量圈定；实体集沿连线流动，操作/遍历卡消费实体集实现批量驱动；
- **双通道连线**：执行链（推模型，事件→级联）+ 数据流（拉模型，属性读取/比较/数学/表达式按需求值）；
- **事件与操作**：启动时/每帧/点击三类触发；设置属性（点分通用属性路径）、FSM 事件/参数、获取子级、原型「接入」口（图数据直传实体脚本）；
- **帧驱动器**：持续旋转、上下浮动、路径巡逻（路径点实体集按序巡回 + 轴往返）、追击目标（自动导航寻路绕行障碍 + 朝向移动方向）、导航移动（对象贴合 Nav Agent 位姿）；
- **控制流**：比较/分支/开关；**中断开关**（电路开关式通断：关断下游执行链与帧驱动器，状态机切状态中断巡逻/导航的实现路径）；
- **逻辑容器（可嵌套）**：**状态机容器**（多状态、状态归属子卡、事件/条件口切换、迁移守卫 `from>to`、同状态去重/可重入）；**行为树容器**（顺序/选择/并行三种模式、条件配对选路、周期重跑、显式「退出」口，嵌套在状态机中随状态自动启停）；
- **变量与自定义节点**：图变量读写、表达式自定义节点、数学节点库；**模块化注入**：`registerModule`/`registerCategory` 注册的新类型/新类别自动可建、自动进右键菜单——扩展节点体系零改核心；
- **运行位置**：场景图在**预览与构建产物**中执行（`graph-behaviors` 解释器随产物下发），编辑器与运行时同一套内核，语义一致。

## kp-2 其它更新

### 客户端重构与多会话窗口

- **会话架构统一重构**：会话键升级为 `SessionKey(root, rel)` 复合键，根除跨项目同路径会话误复用；窗口生命周期改为声明式查表（新增窗口类型只加一行）；多窗口交接统一为单一握手入口，消除启动时序竞态；
- **多会话窗口**：每个项目独立编辑器窗口；场景图窗口动态 `graph-N` 开启、关闭即销毁；同一场景全窗口共享同一份会话数据（跨窗口实时一致）；
- **多窗口基础设施**：预览服务器按窗口分键 + 临时端口（多会话预览不串台）；界面状态持久化从 localStorage 迁移到后端 UI 状态 KV（多窗口可靠跟随）；移除系统边框，自定义标题栏与窗口控制；多窗口多线程/进程五阶段并行优化；启动蒙版全产物装载消除开窗白屏；修复混合显卡黑闪。

### 预览与构建支持状态机和行为树

- `.fsm` 状态机 / `.bt` 行为树**逻辑资产随预览与构建真实运行**（运行器资产随产物打包与引用重写），与编辑器内 Live 视图同一套求值器；
- 场景图内的状态机容器/行为树容器同样在预览与构建中执行（见上）。

### 预览与构建支持导航区域和导航 Agent

- 导航区域（地形/任意网格烘焙可行走场 + SDF）与导航代理（单点/顺序巡回/最近可达，目标移动自动重评估）进入预览与构建运行时；
- 图追击联动导航：追击时自动暂停目标代理巡回、脱离后恢复并自动重寻路；追击移动按导航网格寻路绕行障碍。

### 渲染与运行时修复

- 静态批处理：烘焙前刷新场景世界矩阵（修复同材质网格烘到错误位置而消失）；批处理排除沿父链传播（可动父节点下的子网格不再被烘焙）；脚本图引用实体自动排除出批处理；
- 预览/构建不再默认注入环境光与天空盒半球光（场景说了算，避免亮度叠加）。

## 已知缺陷与边界

- **场景图只在预览/构建运行时执行**：编辑器视口不跑图逻辑，行为验证依赖网页预览（控制台实时回传辅助定位）；
- **图内行为树容器是「卡片编排」而非完整行为树**：selector 模式的条件源与成员按纵向顺序一一配对（无具名绑定，重排会改配对）；parallel 模式每帧重跑成员链，要求卡片幂等；`.bt` 资产里的装饰器（重复/重试/超时/反转）与等待等节点语义在**实体侧 BT 运行器**，图容器不执行它们；
- **状态机容器的迁移模型是「事件名 = 目标状态」**：迁移守卫按 `from>to` 限制方向，尚无「事件 × 源状态」的完整迁移表；同状态重复触发默认忽略（需重入语义须勾选「重复进入」）；
- **追击寻路依赖已烘焙的导航区域**：场景无导航区域或目标不可达时回退直线移动（可能穿障碍）；导航烘焙是静态的，运行期改变障碍物不会自动重烘焙；
- **静态批处理为正确性保守排除**：可动父节点下的整棵子树不参与合并/实例化，动态对象多的场景 DrawCall 优化收益随之减少；
- **实体侧逻辑资产（.fsm/.bt）与图内逻辑容器是两套并行机制**：状态不自动互相同步，需要经事件/条件卡桥接（如 FSM 事件卡同时通知资产运行器与容器）。

## 产品哲学

> **人的有限时间不能耗费在无限的工具学习中。**

TvE Hub 以此为设计原点：一站式覆盖从搭场景到构建导出的完整链路，而非用一堆插件拼装工作流；编辑器与导出产物运行同一套运行时，免去「编辑器里好好的、发布后不一样」的排查成本；脚本、逻辑、资产共用同一套心智模型，内置文档随编辑器即在。工具应当退到幕后，把时间还给创作本身。

场景图是这一哲学的延伸：会拖卡片就会编程——把「写代码扩展行为」降维成「拖节点、连连线」，同时保留脚本与逻辑资产作为高阶出口。

## 功能特性

### 编辑器

- **多会话窗口架构**：首页窗口（项目管理、工程模板、偏好设置、创意工坊、开发者服务）+ 每项目独立编辑器窗口 + 动态场景图窗口；浏览器环境回退单窗口视图切换；
- **项目管理**：新建项目可套用工程模板（类别 → 模板卡片 → 信息与表单三步选择），最近项目卡片支持打开、在文件夹中显示、重命名、移动到系统回收站（可恢复）、移除记录；
- **停靠面板系统**：层级 / 属性（检查器）/ 控制台 / 资产 / 动画 五种面板，支持拖拽停靠、浮动窗口、合并标签页、布局持久化（编辑器与场景图窗口共享同一套停靠工厂）；动画聚焦模式下锁定布局防止误动；
- **四种视图模式**：场景（3D 编辑视口）/ 布局（UI 画布）/ 预览（内嵌网页运行）/ 脚本（代码工作台）；预览与脚本模式暂停编辑器视口渲染以节省资源；
- **检查器与组件**：变换、网格、灯光、相机、物理（刚体/碰撞体）、音源、粒子、脚本组件等卡片式编辑；
- **撤销/保存**：命令式撤销栈，未保存标记，快捷键与工具切换（W/E/R）。

### 场景图（kp-2 新增）

详见顶部「kp-2 重大更新：场景图」。一句话：场景即图、对象即原型——驱动器 + 逻辑卡 + 逻辑容器，不改代码扩展原型行为，预览/构建与编辑器同语义。

### 场景与渲染

- 场景层级、节点多选、拖拽排序、预制体实例化、节点类型图标；
- 粒子系统、阴影、雾效、天空、LOD、静态批处理，WebGL / WebGPU 双渲染后端（不可用时自动回退）；
- **UI 系统**：UI 画布 + Widget（文本/图片/按钮/布局容器）、锚点布局、缩放适配、内置布局配方，可与 3D 场景混合编排；
- **动画编辑器**：关键帧剪辑、曲线编辑、录制、`.anim` 剪辑资产、动画图、骨骼动画（混合/加法层、IK、形态键、骨骼调试）；
- **着色器**：`.shader` 效果着色器资产（Properties 参数 + Hook 钩子），在材质卡片挂载，创意工坊内置 6 个效果示例（边缘光 / 扫描线 / 全息投影 / 溶解消失 / UV 流光 / 顶点波动）。

单位约定：位置/缩放 = 米，旋转 = 度，UI = 100 设计像素，y 向上，前向 = -Z。

### 逻辑与脚本

- **脚本系统**：代码工作台编写 TypeScript（编译、绑定节点、编辑器内智能提示与错误定位），`tve` SDK 提供 `@property` 装饰器声明脚本属性（类型推断/节点引用/组件引用/自动挂载）、`@nodeType` 脚本节点、`engine` 入口（时间、输入（含多点触控）、场景查询、动画、音频、粒子、物理、UI、补间、日志）、`math` 向量/角度工具、`tween` 链式补间（序列/并行、31 种缓动）、`utils`（Delegate/Pool/DataCenter）；
- **逻辑系统**：`.fsm` 状态机 / `.bt` 行为树可视化编辑器（节点画布、连线、黑板参数、事件、自定义右键菜单、适配视图）+ 运行时引擎，层级节点挂 FSM Runner / BT Runner 运行器（资产绑定、自动启动、时间倍率），检查器提供 Live 状态视图（运行控制、事件、强制切换、黑板实时查看），资产保存热重建；脚本侧 `engine.logic` 派发事件、读写黑板、监听状态、注册动作处理器；
- **场景图系统（kp-2 新增）**：独立窗口的节点图编辑，见顶部专章；
- 编辑器与播放器共用同一套求值器，预览/导出语义一致。

### 地形 / 导航 / 物理

- **地形笔刷**：高度雕刻（抬升/压低/压平/平滑）+ splatmap 权重绘制（`.terrainmat` 多层混合材质），绘制实时预览、增量重烤；
- **导航系统**：地形/任意网格烘焙可行走场 + SDF 寻路 + 导航代理（单点/顺序巡回/最近可达三种目标模式，目标移动自动重评估路径），**预览与构建真实运行（kp-2）**；
- **物理**：刚体与碰撞体组件，模拟在独立线程运行，不阻塞编辑与渲染主循环。

### 资产与构建

- **资产系统**：资产面板（导入、重命名、复制路径、按类型筛选），类型覆盖场景、模型、材质（`.mat`）、地形材质（`.terrainmat`）、纹理、音频、着色器、动画、预制体、脚本、逻辑资产（`.fsm`/`.bt`）；模型导入支持 glTF（含 Draco 压缩）、内嵌材质自动提取为 `.mat`、按材质槽位覆盖；项目 `internal/` 提供内置只读资产；
- **创意工坊**：脚本原型（`.ts`）与效果原型（`.shader`）仓库，资产面板右键按原型直接新建项目资产；
- **网页预览**：一键导出独立网页真实运行（保存 + 编译 + 打包运行时），控制台与错误实时回传编辑器，支持系统浏览器打开调试；设备仿真内置常见手机/平板机型（横竖屏、自定义分辨率与 DPR、缩放适配），完整验证移动端表现；
- **构建导出（Web）**：多场景构建（指定主场景入口）、发布模式（资源重命名 + 引用重写 + JSON 压缩）、资产 gzip 归档、CDN 模式、多导出模板；产物为纯静态文件输出到 `<项目>/build/web/`，可直接部署任意静态服务器或对象存储 + CDN；逻辑资产（`.fsm`/`.bt`）与场景图（`.graph`）随场景自动打包（kp-2 修复 Release 打包引用重写）。

## 项目目录结构

新建项目自动生成标准结构：

```
<项目根>/
├─ project.config.json   项目设置（版本、主场景、显示、物理、标签与层）
├─ build.config.json     构建配置（构建面板保存后生成）
├─ assets/               场景、模型、纹理、音频、材质、着色器、动画、预制体
├─ graph/                场景图（与场景绑定的行为图，随场景自动保存）
├─ src/                  TS 脚本（只能放脚本）
├─ internal/             内置只读资产（只可引用不可修改）
└─ build/web/            构建产物（构建后生成）
```

## 仓库结构

```
src/
  framework/     # 编辑器引擎（场景/动画/物理/逻辑/导航/地形/脚本/图注册表……各子系统）
  runtime/       # 播放器网页运行时（预览与构建产物使用，编辑器共用；含场景图内核）
  graph-window/  # 场景图编辑窗口（Vue Flow 画布、卡片、检查器、会话）
  app/           # 首页与编辑器窗口应用壳
  docks/         # 编辑器/图窗口共享停靠系统工厂
  components/    # 通用业务组件
  ui-kit/        # 编辑器 UI 组件库
  lib/           # 数据层门面（唯一允许直接调用桌面端 IPC 的位置）
public/docs/     # 内置文档：editor/（编辑器，含 graph.md 场景图）+ sdk/（脚本 API）
src-tauri/       # 桌面端后端（项目/资产管理、预览构建、窗口会话、资产协议、监视器）
scripts/         # 构建/生成脚本与 smoke 冒烟测试
```

分层守卫：全仓仅 `src/lib/` 允许直接调用桌面端 IPC，构建前由 `scripts/check-layers.mjs` 检查。

## 快速开始

环境要求：Node.js 18+、pnpm、Rust 工具链（构建桌面端安装包需要）。

```bash
pnpm install

# 浏览器开发模式（单窗口回退）
pnpm dev

# 桌面端开发模式（多会话窗口）
pnpm tauri dev

# 前端构建（含运行时打包、生成文件、类型检查、分层检查）
pnpm build

# 桌面端安装包构建
pnpm build:portable
```

## 质量检查

项目以 smoke 冒烟脚本做回归测试（Node 直跑），覆盖网格、物理、组件、着色器、粒子、阴影、地形、状态机、逻辑引擎/运行时、**场景图运行时（节点/容器/朝向/寻路）、批处理、分层渲染**、导航、输入、补间、脚本钩子等子系统：

```bash
pnpm smoke:logic-engine     # 示例：逻辑引擎 81 项
pnpm smoke:graph-runtime    # 示例：场景图运行时 99 项（真实产物直跑）
pnpm smoke:graph            # 示例：场景图注册表/菜单/会话 268 项
pnpm smoke:fsm              # 示例：状态机/行为树求值
pnpm check:layers           # 分层守卫检查
```

全部脚本见 `package.json` 的 `scripts`。

## 支持我们

TvE Hub 由独立开发者利用业余时间持续打磨——从场景编辑到场景图，每一个功能都源自「让创作少一步折腾」的执念。项目完全开源免费，但我们也很现实：开发、测试设备与运行成本都在真实发生。

如果这个项目对你有帮助，或者你认同「可视化创作工具不该有高学习成本」这件事：

- ⭐ **给项目点一个 Star** —— 这是对独立开发者最直接的支持。Star 不花一分钱，却能让更多创作者搜到这里，也是我们坚持更新最有效的强心剂；
- 💰 **考虑赞助我们** —— 每一份支持都会直接投入在开发与运行成本上。赞助渠道：[爱发电](#)(即将上线，不妨先点个star)。

哪怕只是提一个 Issue、纠正一段文档，都是实实在在的帮助。感谢每一个愿意停下来看一眼的你。
